Static Routing

Learn how to manually configure routes to connect remote networks using IPv4 and IPv6.

Step 01

Topology & IP Addressing

Understand the network topology before configuring routes. We have two remote LANs (192.168.1.0/24 and 192.168.2.0/24) connected via a WAN link (10.0.0.0/30).

Network Setup

Router 1 (R1) needs to know how to reach the LAN behind Router 2 (R2), and vice versa.

topology-map.txt
/* Network Topology */ [LAN 1: 192.168.1.0/24] --- (G0/0: 192.168.1.254) [ Router 1 (R1) ] (S0/0/0: 10.0.0.1) | [ WAN: 10.0.0.0/30 ] | (S0/0/0: 10.0.0.2) [ Router 2 (R2) ] (G0/0: 192.168.2.254) --- [LAN 2: 192.168.2.0/24]
Enterprise Router Infrastructure
Step 02

Directly Connected Networks

Before static routes can be added, interfaces must be configured with IP addresses and enabled.

r1-interface.conf
! Configure Router 1 (R1) Interfaces R1(config)# interface gigabitEthernet 0/0 R1(config-if)# ip address 192.168.1.254 255.255.255.0 R1(config-if)# no shutdown R1(config-if)# exit R1(config)# interface serial 0/0/0 R1(config-if)# ip address 10.0.0.1 255.255.255.252 R1(config-if)# no shutdown R1(config-if)# exit ! Note: R2 is configured similarly with 192.168.2.254 and 10.0.0.2
Step 03

Configure Next-Hop Static Route

Instruct R1 on how to reach LAN 2 by pointing to R2's WAN IP address as the next hop.

IPv4 Static Route

The syntax is: ip route [destination_network] [subnet_mask] [next_hop_ip]

static-route.conf
! On Router 1 (R1): Route to LAN 2 (192.168.2.0/24) via R2 (10.0.0.2) R1(config)# ip route 192.168.2.0 255.255.255.0 10.0.0.2 ! On Router 2 (R2): Route to LAN 1 (192.168.1.0/24) via R1 (10.0.0.1) R2(config)# ip route 192.168.1.0 255.255.255.0 10.0.0.1
Step 04

Configure Default Route

A default route is used when the router does not know how to reach a specific network (often used for Internet access).

default-route.conf
! Configure Quad-Zero (0.0.0.0) to route ALL unknown traffic to ISP R1(config)# ip route 0.0.0.0 0.0.0.0 10.0.0.2 ! Alternatively, use the exit interface (Directly Attached) R1(config)# ip route 0.0.0.0 0.0.0.0 serial 0/0/0
Core Network Router Configuration
Step 05

IPv6 Static Routing

Enable IPv6 routing and configure static routes using IPv6 addressing.

IPv6 Configuration

Unlike IPv4, IPv6 routing is disabled by default on Cisco routers and must be enabled globally.

ipv6-routing.conf
! Enable IPv6 Routing R1(config)# ipv6 unicast-routing ! Configure Next-Hop IPv6 Static Route R1(config)# ipv6 route 2001:db8:2::/64 2001:db8:acad::2 ! Configure IPv6 Default Route R1(config)# ipv6 route ::/0 2001:db8:acad::2
Step 06

Verify & Troubleshoot

Verify your routes and test connectivity using ping and traceroute.

verify-routes.conf
R1# show ip route Codes: L - Local, C - Connected, S - Static, * - candidate default S 192.168.2.0/24 [1/0] via 10.0.0.2 C 10.0.0.0/30 is directly connected, Serial0/0/0 L 10.0.0.1/32 is directly connected, Serial0/0/0 C 192.168.1.0/24 is directly connected, GigabitEthernet0/0 L 192.168.1.254/32 is directly connected, GigabitEthernet0/0 S* 0.0.0.0/0 [1/0] via 10.0.0.2 R1# ping 192.168.2.1 Type escape sequence to abort.
