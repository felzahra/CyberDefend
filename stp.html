Spanning Tree Protocol

Prevent disastrous broadcast storms and infinite loops in redundant switched networks using STP (802.1D) and Rapid STP (802.1w).

Step 01

STP Concepts & Port Roles

Spanning Tree Protocol (STP) calculates a loop-free logical topology by placing redundant ports into a "Blocking" state. If a primary link fails, STP unblocks the redundant port.

Port Roles

Root Port (RP): The port with the lowest cost path to the Root Bridge. One per non-root switch.
Designated Port (DP): Forwarding ports. One on each network segment.
Alternate Port (AP): Blocked port providing redundancy.

stp-states.txt
/* 802.1D Port States */ Blocking -> Listening -> Learning -> Forwarding (Takes ~30-50 seconds to converge) /* Rapid STP (802.1w) Port States */ Discarding -> Learning -> Forwarding (Converges in under a second)
Redundant Switched Network Topology
Step 02

Root Bridge Election

The Root Bridge is the center of the STP topology. All ports on the Root Bridge are Designated (Forwarding). It is elected based on the lowest Bridge ID (Priority + MAC Address). You should manually control this.

Configuring Core Switch (SW1)

Make your strongest Core switch the Root Bridge by lowering its priority. Use Rapid STP (mode rapid-pvst) for faster convergence.

root-bridge.conf
! 1. Change STP mode to Rapid-PVST SW1(config)# spanning-tree mode rapid-pvst ! 2. Make SW1 the Root Bridge for VLAN 10 SW1(config)# spanning-tree vlan 10 root primary ! 3. Make SW2 the Secondary Root Bridge (On SW2) SW2(config)# spanning-tree vlan 10 root secondary ! Note: 'root primary' lowers priority to 24576. 'root secondary' lowers it to 28672.
Step 03

Configure PortFast

Access ports connected to PCs and servers should not wait 30 seconds for STP to transition to Forwarding. PortFast skips the Listening/Learning states, bringing the port up immediately.

portfast.conf
! Enable PortFast globally for all access ports SW1(config)# spanning-tree portfast default ! Or enable PortFast manually on specific interfaces SW1(config)# interface gigabitEthernet 0/1 SW1(config-if)# switchport mode access SW1(config-if)# spanning-tree portfast SW1(config-if)# exit
Access Port Configuration
Step 04

Configure BPDU Guard

If an unauthorized switch is plugged into an access port, it can send BPDUs and disrupt the STP topology. BPDU Guard puts the port into "Errdisable" state if it receives a BPDU, protecting the network.

BPDU Guard & Recovery

Always pair BPDU Guard with Errdisable recovery to automatically bring the port back up after a set time once the rogue switch is removed.

bpduguard.conf
! 1. Enable BPDU Guard globally on all PortFast ports SW1(config)# spanning-tree portfast bpduguard default ! 2. Enable Errdisable Recovery (Auto-re-enable port after 300 seconds) SW1(config)# errdisable recovery cause bpduguard SW1(config)# errdisable recovery interval 300
