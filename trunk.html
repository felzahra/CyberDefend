VLAN Trunking

Configure 802.1Q trunk links between switches to carry multiple VLANs across a single physical link.

Step 01

Create Prerequisite VLANs

Before configuring a trunk, the VLANs must exist in the database on both switches. We will create VLAN 10, 20, and 99.

SW1 & SW2 Configuration

Run these commands on both Switch 1 and Switch 2 so they share the same VLAN database.

vlan-db.conf
SW1(config)# vlan 10 SW1(config-vlan)# name SALES SW1(config-vlan)# exit SW1(config)# vlan 20 SW1(config-vlan)# name IT SW1(config-vlan)# exit SW1(config)# vlan 99 SW1(config-vlan)# name NATIVE SW1(config-vlan)# exit
Switch Interconnectivity
Step 02

Configure Trunk on SW1

Configure the interface connecting to SW2 as a trunk port so it can tag and carry multiple VLAN frames.

trunk-sw1.conf
SW1(config)# interface gigabitEthernet 0/1 ! (Optional) Required on older L3 switches like 3560/3650 SW1(config-if)# switchport trunk encapsulation dot1q SW1(config-if)# switchport mode trunk SW1(config-if)# exit
Step 03

Configure Trunk on SW2

Configure the opposite side of the link on SW2 identically to SW1 to establish the trunk link.

trunk-sw2.conf
SW2(config)# interface gigabitEthernet 0/1 ! (Optional) Required on older L3 switches like 3560/3650 SW2(config-if)# switchport trunk encapsulation dot1q SW2(config-if)# switchport mode trunk SW2(config-if)# exit
Step 04

Configure Native VLAN

By default, VLAN 1 is the native VLAN. For security, it is best practice to change the native VLAN to an unused VLAN (like 99) on both ends of the trunk.

native-vlan.conf
! Configure Native VLAN on SW1 SW1(config)# interface gigabitEthernet 0/1 SW1(config-if)# switchport trunk native vlan 99 ! Configure Native VLAN on SW2 (Must Match!) SW2(config)# interface gigabitEthernet 0/1 SW2(config-if)# switchport trunk native vlan 99
802.1Q Tagging on Trunk Links
Step 05

Restrict Allowed VLANs

By default, a trunk allows all VLANs (1-4094). For security and bandwidth management, prune the trunk to only carry the active VLANs.

allowed-vlans.conf
SW1(config)# interface gigabitEthernet 0/1 SW1(config-if)# switchport trunk allowed vlan 10,20,99 ! To ADD a vlan to an existing trunk list later: SW1(config-if)# switchport trunk allowed vlan add 30 ! To REMOVE a vlan from the list: SW1(config-if)# switchport trunk allowed vlan remove 30
Step 06

Verify Trunk Configuration

Verify the trunk status, native VLAN, and allowed VLANs on the switch interfaces.

verify-trunk.conf
SW1# show interfaces trunk Port Mode Encapsulation Status Native vlan Gi0/1 on 802.1q trunking 99 Port Vlans allowed on trunk Gi0/1 10,20,99 Port Vlans allowed and active in management domain Gi0/1 10,20,99 Port Vlans in spanning tree forwarding state and not pruned Gi0/1 10,20,99 SW1# show interfaces gigabitEthernet 0/1 switchport Name: Gi0/1 Switchport: Enabled Administrative Mode: trunk Operational Mode: trunk Administrative Native VLAN: 99 Trunking VLANs Enabled: 10,20,99
