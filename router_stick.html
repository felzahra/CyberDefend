Router-on-a- Stick

Implement inter-VLAN routing using 802.1Q subinterfaces on a single router interface.

Step 01

Configure Switch Trunk Link

The switch port connecting to the router must be configured as a trunk to carry multiple VLANs.

SW1 Configuration

Enable trunking on the interface connected to the router and restrict it to the necessary VLANs.

sw1-trunk.conf
SW1(config)# interface gigabitEthernet 0/1 SW1(config-if)# switchport mode trunk SW1(config-if)# switchport trunk allowed vlan 10,20,99 SW1(config-if)# exit
Switch Connected to Router
Step 02

Enable Main Router Interface

The physical interface on the router must be enabled, but it does not need an IP address.

r1-physical-int.conf
R1(config)# interface gigabitEthernet 0/0 R1(config-if)# no shutdown R1(config-if)# exit
Step 03

Create Sub-interfaces

Create a virtual sub-interface for each VLAN. Configure 802.1Q encapsulation and assign an IP address that will act as the gateway for devices in that VLAN.

r1-subinterfaces.conf
! Sub-interface for VLAN 10 (SALES) R1(config)# interface gigabitEthernet 0/0.10 R1(config-subif)# encapsulation dot1Q 10 R1(config-subif)# ip address 192.168.10.1 255.255.255.0 R1(config-subif)# exit ! Sub-interface for VLAN 20 (IT) R1(config)# interface gigabitEthernet 0/0.20 R1(config-subif)# encapsulation dot1Q 20 R1(config-subif)# ip address 192.168.20.1 255.255.255.0 R1(config-subif)# exit
Router CLI Configuration
Step 04

Configure Native VLAN Sub-interface

It is best practice to map the native VLAN to a sub-interface to prevent untagged traffic from being routed unexpectedly.

r1-native-vlan.conf
! Sub-interface for Native VLAN 99 R1(config)# interface gigabitEthernet 0/0.99 R1(config-subif)# encapsulation dot1Q 99 native R1(config-subif)# exit
Step 05

Configure End Devices

Assign IP addresses to PCs and set their default gateway to the sub-interface IP of their respective VLAN.

PC Configuration

For a PC in VLAN 10, set its Default Gateway to 192.168.10.1.

pc-config.txt
/* PC1 in VLAN 10 */ IP Address: 192.168.10.10 Subnet Mask: 255.255.255.0 Default Gateway: 192.168.10.1 /* PC2 in VLAN 20 */ IP Address: 192.168.20.10 Subnet Mask: 255.255.255.0 Default Gateway: 192.168.20.1
Step 06

Verify & Test Connectivity

Verify the router's routing table and test connectivity between VLANs.

verify-routing.conf
R1# show ip route Codes: L - Local, C - Connected C 192.168.10.0/24 is directly connected, GigabitEthernet0/0.10 L 192.168.10.1/32 is directly connected, GigabitEthernet0/0.10 C 192.168.20.0/24 is directly connected, GigabitEthernet0/0.20 L 192.168.20.1/32 is directly connected, GigabitEthernet0/0.20 R1# show ip interface brief Interface IP-Address OK? Method Status Protocol GigabitEthernet0/0 unassigned YES unset up up GigabitEthernet0/0.10 192.168.10.1 YES manual up up GigabitEthernet0/0.20 192.168.20.1 YES manual up up GigabitEthernet0/0.99 unassigned YES unset up up ! Ping from PC1 (VLAN 10) to PC2 (VLAN 20) C:\> ping 192.168.20.10 Pinging 192.168.20.10 with 32 bytes of data: Reply from 192.168.20.10: bytes=32 time=1ms TTL=127 Reply from 192.168.20.10: bytes=32 time=1ms TTL=127
