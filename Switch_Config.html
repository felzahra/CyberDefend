Basic Switch Configuration

Learn how to initialize, secure, and manage a Cisco Catalyst switch from the Command Line Interface (CLI).

Step 01

Entering the CLI

Connect to the switch via console cable and enter Privileged EXEC mode.

Console Connection

Use a rollover cable connected to the console port. Open a terminal emulator (PuTTY/Tera Term) with 9600 baud rate.

cli-initial.access
! Press Enter to wake up the console Switch> enable Switch# configure terminal Switch(config)#
Cisco Catalyst Network Switch
Step 02

Change Hostname

Assign a unique name to the switch for identification in the network.

hostname.conf
Switch(config)# hostname SW1-Floor1 SW1-Floor1(config)#
Step 03

Secure Access

Protect the switch by setting console, privileged EXEC, and VTY passwords.

security.conf
! Secure Privileged EXEC Mode SW1-Floor1(config)# enable secret class12345 ! Secure Console Line SW1-Floor1(config)# line console 0 SW1-Floor1(config-line)# password cisco SW1-Floor1(config-line)# login SW1-Floor1(config-line)# exit ! Secure VTY (Remote Access) Lines SW1-Floor1(config)# line vty 0 15 SW1-Floor1(config-line)# password cisco SW1-Floor1(config-line)# login SW1-Floor1(config-line)# exit ! Encrypt all plaintext passwords SW1-Floor1(config)# service password-encryption
Step 04

Management IP & Gateway

Configure the Switch Virtual Interface (SVI) to allow remote management.

management-ip.conf
! Configure SVI on VLAN 1 (or dedicated Mgmt VLAN) SW1-Floor1(config)# interface vlan 1 SW1-Floor1(config-if)# ip address 192.168.1.10 255.255.255.0 SW1-Floor1(config-if)# no shutdown SW1-Floor1(config-if)# exit ! Set Default Gateway SW1-Floor1(config)# ip default-gateway 192.168.1.1
Step 05

Save Configuration

Save the running configuration to NVRAM so it persists after a reboot.

save-config.conf
SW1-Floor1(config)# end SW1-Floor1# copy running-config startup-config Destination filename [startup-config]? [Press Enter] Building configuration... [OK]

Layer 2 Configuration

L2 Switching (VLANs & Trunks)

Layer 2 switches handle data frames using MAC addresses. Create VLANs and configure access/trunk ports to segment network traffic.

VLANs & Access Ports

Assign specific ports to VLANs to isolate broadcast domains.

l2-vlan-config.conf
! Create VLAN 10 and assign a name SW1(config)# vlan 10 SW1(config-vlan)# name SALES SW1(config-vlan)# exit ! Configure interface as an Access Port SW1(config)# interface gigabitEthernet 1/0/1 SW1(config-if)# switchport mode access SW1(config-if)# switchport access vlan 10 SW1(config-if)# spanning-tree portfast SW1(config-if)# exit ! Configure Trunk Port (for switch-to-switch connection) SW1(config)# interface gigabitEthernet 1/0/24 SW1(config-if)# switchport mode trunk SW1(config-if)# switchport trunk allowed vlan 10,20,30

Layer 3 Configuration

L3 Switching (Inter-VLAN Routing)

Layer 3 switches can route traffic between VLANs. Enable IP routing and assign IP addresses to SVIs to act as gateways.

Enable Routing & SVI Gateways

By default, L3 switches act as L2 switches. You must enable routing globally.

l3-routing-config.conf
! Enable Layer 3 routing globally SW1(config)# ip routing ! Configure SVI for VLAN 10 (Gateway for Sales) SW1(config)# interface vlan 10 SW1(config-if)# ip address 192.168.10.1 255.255.255.0 SW1(config-if)# no shutdown SW1(config-if)# exit ! Configure SVI for VLAN 20 (Gateway for IT) SW1(config)# interface vlan 20 SW1(config-if)# ip address 192.168.20.1 255.255.255.0 SW1(config-if)# no shutdown SW1(config-if)# exit ! (Optional) Configure a Routed Port for uplink to Router SW1(config)# interface gigabitEthernet 1/0/48 SW1(config-if)# no switchport SW1(config-if)# ip address 10.0.0.2 255.255.255.252 SW1(config-if)# no shutdown ! Verify routing table SW1# show ip route
