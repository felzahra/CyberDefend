2. Core Switch - Primary

ArubaOS-CX
hostname DPA-Core-Primary
Sets the device hostname as the primary Core Switch of Damietta Port Authority.
spanning-tree priority 0
Forces this primary core switch to act as the Root Bridge for the entire network.
interface lag 128 description ISL-link vlan trunk native 1 tag lacp mode active
Defines the Inter-Switch Link (ISL) high-speed interconnect dedicated to state synchronization with the Secondary switch.
interface vlan 2 ip address 10.0.2.2/24 active-gateway ip mac 02:01:00:00:00:02 active-gateway ip 10.0.2.1
Primary physical IP is `10.0.2.2`. Shares Virtual IP `10.0.2.1` to ensure hosts experience no routing disruption during failover.
interface vlan 244 ip address 10.0.244.2/24 active-gateway ip mac 02:01:00:00:00:02 active-gateway ip 10.0.244.1
ND4 Management VLAN. Primary physical IP `10.0.244.2`. Shares Virtual IP `10.0.244.1` with Secondary.
vsx role primary keepalive peer 10.0.4.3 source 10.0.4.2
Sets role to `primary` and configures keepalive heartbeat source IP `10.0.4.2` peering with `10.0.4.3`.

3. Core Switch - Secondary

ArubaOS-CX
hostname DPA-Core-Secondary
Sets the device hostname as the secondary Core Switch in the VSX cluster.
spanning-tree priority 1
Spanning Tree priority set higher than Primary. Acts as the backup Root Bridge if Primary fails.
interface lag 128 description ISL-link vlan trunk native 1 tag lacp mode active
Mirrors the ISL configuration to establish the high-speed interconnect required for VSX synchronization.
interface vlan 2 ip address 10.0.2.3/24 active-gateway ip mac 02:01:00:00:00:02 active-gateway ip 10.0.2.1
Secondary physical IP is `10.0.2.3`. Shares the exact same Virtual MAC and Virtual IP (`10.0.2.1`) as Primary.
interface vlan 244 ip address 10.0.244.3/24 active-gateway ip mac 02:01:00:00:00:02 active-gateway ip 10.0.244.1
ND4 Management VLAN. Secondary physical IP `10.0.244.3`. Shares Virtual IP `10.0.244.1` with Primary.
vsx role secondary keepalive peer 10.0.4.2 source 10.0.4.3
Sets role to `secondary`. Keepalive source and peer IPs are reversed to complete the bidirectional heartbeat.

4. Distribution Switch - Primary

ArubaOS-CX (ND4-prim)
hostname ND4-prim
Sets the hostname for the primary Distribution Switch in Node 4.
interface lag 244 multi-chassis vlan trunk native 14 vlan trunk allowed all lacp mode active
Uplink MC-LAG connection towards the Core Switches. Native VLAN is 14, carrying all routed subnets.
interface vlan 44 ip address 10.0.44.2/24 active-gateway ip mac 02:01:00:04:41:01 active-gateway ip 10.0.44.1 ip helper-address 10.0.10.12
Voice VLAN 44. Primary physical IP `10.0.44.2`. Virtual Gateway IP `10.0.44.1`. DHCP relay forwards requests to `10.0.10.12`.
interface vlan 16 vsx-sync active-gateways ip address 10.0.16.3/24 active-gateway ip 10.0.16.1
Data VLAN 16. Primary physical IP `10.0.16.3`. Shares Virtual Gateway IP `10.0.16.1` with Secondary switch.
interface vlan 244 ip address 10.0.244.2/24 active-gateway ip mac 02:01:00:04:41:01 active-gateway ip 10.0.244.1
Management VLAN 244. Primary physical IP `10.0.244.2`. Shares Virtual IP `10.0.244.1` with Secondary.
ip route 0.0.0.0/0 10.0.14.2
Default Route directing all non-local traffic up to the Core Switch SVI interface `10.0.14.2`.

5. Distribution Switch - Secondary

ArubaOS-CX (ND4-Sec)
hostname ND4-Secondary
Sets the hostname for the secondary Distribution Switch in Node 4.
interface lag 244 multi-chassis vlan trunk native 14 vlan trunk allowed all lacp mode active
Mirrors the MC-LAG uplink to Core, allowing simultaneous active links to both Core switches.
interface vlan 44 ip address 10.0.44.3/24 active-gateway ip mac 02:01:00:04:41:01 active-gateway ip 10.0.44.1
Secondary physical IP `10.0.44.3`. Shares Virtual IP `10.0.44.1` and vMAC for transparent endpoint gateway failover.
interface vlan 16 vsx-sync active-gateways ip address 10.0.16.2/24 active-gateway ip 10.0.16.1
Data VLAN 16 on Secondary. Physical IP `10.0.16.2`. Shares Virtual Gateway IP `10.0.16.1` with Primary switch.
interface vlan 244 ip address 10.0.244.3/24 active-gateway ip mac 02:01:00:04:41:01 active-gateway ip 10.0.244.1
Management VLAN 244 on Secondary. Physical IP `10.0.244.3`. Shares Virtual IP `10.0.244.1` with Primary.
ip route 0.0.0.0/0 10.0.14.2
Mirrors the Primary's default route, ensuring that if failover occurs, traffic is still correctly forwarded up to the Core switches.
