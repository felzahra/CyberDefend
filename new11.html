Understanding the Architecture

3-Tier Switch Architecture

Core Layer

L3

The backbone of the network. High-speed, high-throughput switching with inter-VLAN routing and OSPF. Connects to distribution switches and router/uplink.

  • • Layer 3 routing (SVI interfaces)
  • • OSPF for dynamic routing
  • • 10Gbps uplinks
  • • Redundancy & fast convergence

Distribution Layer

L2/L3

Aggregation point between core and edge. Implements policies, ACLs, VLAN trunking, and can do L3 routing if needed.

  • • VLAN trunk to core (Tagged)
  • • Access ports to edge (Tagged)
  • • Policy enforcement & ACLs
  • • Spanning Tree root bridge

Edge Layer

L2

Connects end devices (PCs, printers, phones). Access ports assign VLANs. Uplinks to distribution via trunks.

  • • Access ports (Untagged VLAN)
  • • Port security & storm control
  • • Trunk uplink to distribution
  • • PoE for IP phones/APs

Step 1

Core Switch — Full Configuration

CORE-SW is the L3 backbone. It creates VLANs, SVIs for routing, trunk links to both distribution switches, and OSPF.

HPE Aruba 5406R — Modular core switch with 10Gbps uplinks

1

CORE-SW — VLANs, Trunks, SVI, OSPF

CORE-SW — Complete Configuration
###############################################################
#  CORE-SW — HPE Aruba 5406R / ArubaOS-CX                   #
###############################################################

##### ============================================ #####
#####  STEP 1A: HOSTNAME & MANAGEMENT IP         #####
##### ============================================ #####

hostname CORE-SW

# Create management VLAN (VLAN 99) and assign IP
vlan 99
   name MGMT
   exit
interface vlan 99
   ip address 10.0.0.1/24
   exit

# Set default gateway for management
ip default-gateway 10.0.0.254


##### ============================================ #####
#####  STEP 1B: CREATE VLANS 10, 20, 30          #####
##### ============================================ #####

vlan 10
   name STAFF
   exit

vlan 20
   name SERVERS
   exit

vlan 30
   name GUESTS
   exit

# Verify VLANs
show vlan
#  VLAN ID | Name    | Status | Ports
#  ------- | ------- | ------ | -----
#  1       | DEFAULT | Up     | ...
#  10      | STAFF   | Up     |
#  20      | SERVERS | Up     |
#  30      | GUESTS  | Up     |
#  99      | MGMT    | Up     |


##### ================================================ #####
#####  STEP 1C: SVI — INTER-VLAN ROUTING (L3)       #####
#####  These are the gateways for each VLAN          #####
##### ================================================ #####

interface vlan 10
   ip address 192.168.10.1/24
   exit

interface vlan 20
   ip address 192.168.20.1/24
   exit

interface vlan 30
   ip address 192.168.30.1/24
   exit

# Enable IP routing on the switch
ip routing

# Verify SVIs
show ip interface brief
# Interface     IP Address      Status  Protocol
# ------------- --------------- ------  --------
# vlan 10       192.168.10.1    Up      Up
# vlan 20       192.168.20.1    Up      Up
# vlan 30       192.168.30.1    Up      Up
# vlan 99       10.0.0.1        Up      Up


##### =================================================== #####
#####  STEP 1D: TRUNK LINKS TO DIST-SW1 (3 links)       #####
#####  Ports 1/1/1, 1/1/2, 1/1/3 → Tagged VLAN 10,20,30  #####
##### =================================================== #####

interface 1/1/1
   no shutdown
   speed 10gforce
   lacp active
   exit

interface 1/1/2
   no shutdown
   speed 10gforce
   lacp active
   exit

interface 1/1/3
   no shutdown
   speed 10gforce
   lacp active
   exit

# Create LAG (Link Aggregation Group) for 3 links to DIST-SW1
interface lag 1
   no shutdown
   lacp key 1
   exit

# Assign ports to LAG 1
interface 1/1/1
   lag 1
   exit
interface 1/1/2
   lag 1
   exit
interface 1/1/3
   lag 1
   exit

# Configure LAG 1 as trunk with tagged VLANs
interface lag 1
   tagged vlan 10,20,30
   exit


##### =================================================== #####
#####  STEP 1E: TRUNK LINKS TO DIST-SW2 (3 links)       #####
#####  Ports 1/1/4, 1/1/5, 1/1/6 → Tagged VLAN 10,20,30  #####
##### =================================================== #####

interface 1/1/4
   no shutdown
   speed 10gforce
   lacp active
   exit
interface 1/1/5
   no shutdown
   speed 10gforce
   lacp active
   exit
interface 1/1/6
   no shutdown
   speed 10gforce
   lacp active
   exit

# Create LAG 2 for 3 links to DIST-SW2
interface lag 2
   no shutdown
   lacp key 2
   exit

interface 1/1/4
   lag 2
   exit
interface 1/1/5
   lag 2
   exit
interface 1/1/6
   lag 2
   exit

interface lag 2
   tagged vlan 10,20,30
   exit


##### ============================================ #####
#####  STEP 1F: OSPF ROUTING                    #####
##### ============================================ #####

router ospf 1
   # Advertise VLAN networks
   network 192.168.10.0/24 area 0.0.0.0
   network 192.168.20.0/24 area 0.0.0.0
   network 192.168.30.0/24 area 0.0.0.0
   network 10.0.0.0/24 area 0.0.0.0
   # Set router ID
   router-id 1.1.1.1
   exit

# Default route toward upstream router
ip route 0.0.0.0/0 10.0.0.254


##### ============================================ #####
#####  STEP 1G: SPANNING TREE (CORE IS ROOT)     #####
##### ============================================ #####

spanning-tree
spanning-tree priority 0
   # Priority 0 = root bridge for all VLANs

spanning-tree vlan 10 priority 0
spanning-tree vlan 20 priority 0
spanning-tree vlan 30 priority 0


##### ============================================ #####
#####  SAVE CONFIGURATION                        #####
##### ============================================ #####

write memory
# Configuration saved.

Step 6

Routing Declaration — OSPF & Static

The core switch handles all inter-VLAN routing via SVIs and advertises routes via OSPF to the upstream router.

OSPF Area 0 — Core switch advertises all VLAN subnets

6

Full Routing Configuration on CORE-SW

CORE-SW — Routing (OSPF + Static)
##### ================================================ #####
#####  STATIC ROUTES                                #####
##### ================================================ #####

# Default route to upstream router/internet
ip route 0.0.0.0/0 10.0.0.254

# Static route to management network (if separate)
ip route 10.0.0.0/24 vlan 99


##### ================================================ #####
#####  OSPF CONFIGURATION                           #####
##### ================================================ #####

router ospf 1
   # Set unique router ID
   router-id 1.1.1.1
   exit

# Advertise each VLAN network into OSPF Area 0
router ospf 1
   area 0.0.0.0 vlan 10
   area 0.0.0.0 vlan 20
   area 0.0.0.0 vlan 30
   area 0.0.0.0 vlan 99
   exit

# Alternative syntax (network-based):
# router ospf 1
#    network 192.168.10.0/24 area 0.0.0.0
#    network 192.168.20.0/24 area 0.0.0.0
#    network 192.168.30.0/24 area 0.0.0.0
#    network 10.0.0.0/24 area 0.0.0.0
# exit


##### ================================================ #####
#####  REDISTRIBUTE STATIC INTO OSPF                 #####
#####  (So upstream router learns the default route)  #####
##### ================================================ #####

router ospf 1
   redistribute static
   exit


##### ================================================ #####
#####  OSPF ON UPSTREAM ROUTER (if HPE/Aruba)       #####
##### ================================================ #####

# On the upstream ROUTER:
router ospf 1
   router-id 2.2.2.2
   area 0.0.0.0 10.0.0.0/24
   exit

# Default route back to core
ip route 192.168.10.0/24 10.0.0.1
ip route 192.168.20.0/24 10.0.0.1
ip route 192.168.30.0/24 10.0.0.1


##### ============================================ #####
#####  ROUTING FLOW DIAGRAM                     #####
##### ============================================ #####
#
#  PC1 (192.168.10.10) wants to reach PC4 (192.168.30.10)
#
#  1. PC1 sends packet to its gateway: 192.168.10.1
#     (CORE-SW VLAN 10 SVI)
#
#  2. CORE-SW looks up route: 192.168.30.0/24
#     → Directly connected via VLAN 30 SVI
#
#  3. CORE-SW forwards out LAG 2 → DIST-SW2
#     (tagged VLAN 30)
#
#  4. DIST-SW2 forwards out LAG 2 → EDGE-SW2
#     (tagged VLAN 30)
#
#  5. EDGE-SW2 strips VLAN tag, sends out port 1
#     (untagged access port in VLAN 30)
#
#  6. PC4 (192.168.30.10) receives the packet!
#

write memory

Inter-VLAN Routing Flow (VLAN 10 → VLAN 30)

PC1 — 192.168.10.10 (VLAN 10, EDGE-SW1 port 1)
EDGE-SW1 → Trunk (tagged VLAN10) → DIST-SW1 → Trunk (tagged VLAN10) → CORE-SW
CORE-SW L3 Routing: SVI vlan10 (192.168.10.1) → SVI vlan30 (192.168.30.1) — Route lookup in routing table
CORE-SW → Trunk (tagged VLAN30) → DIST-SW2 → Trunk (tagged VLAN30) → EDGE-SW2
PC4 — 192.168.30.10 (VLAN 30, EDGE-SW2 port 1)
