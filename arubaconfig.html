🌐

VLAN Gateway

Serves as the default gateway for 20+ VLANs (112, 126-137, 140, 142-146, etc.). Each VLAN interface has a /24 IP.

📨

DHCP Relay

Relays DHCP requests to 3 servers: 10.0.10.12, 10.0.10.13, 10.0.10.14. UDP helper also configured for broadcast services.

🗺️

OSPF Peer

OSPF Area 0 on VLAN 14 (10.0.14.1). Static default route via 10.0.14.2 (Core). Redistributes direct and static.

⛓️

24x LACP Downlinks

Bridge-Aggregation 1-24, each connecting to one access switch (E401-E424). Dynamic LACP with MAD enabled.

👥

VSX + Keepalive

Two chassis in a VSX pair. ISL is LAG 128. Keepalive link on port 1/1/48 detects split-brain. VSX-sync enabled globally and per-VLAN.

📊

sFlow + SNMP v3

sFlow to 10.0.10.76:6343 on all uplink/downlink ports. SNMP v3 with MD5+AES128 for secure NMS integration.

OSPF Area 0 Hub

Peers with all 6 distribution switches via dedicated OSPF VLANs (11-16). Redistributes direct and static routes into OSPF.

👑

STP Root Bridge

STP instance 0 priority set to 0 — the absolute root for the entire Layer 2 topology. All distribution switches converge to this.

🏗️

Server Farm Trunks

4x LACP trunks (101-104) to server farms and backup systems. Carrying VLANs 4 (VM Desktops), 9 (Server Mgmt), 10 (Server Farm).

🌍

WAN + Default Route

Default route 0.0.0.0/0 via 10.0.250.250. VLAN 441 (WAN) ports, VLAN 250 for upstream routing. Internet egress point.

🛡️

ACL 3000

Filters traffic: denies destination 10.0.8.0/24, permits source 172.28.0.0/16. Applied for security segmentation.

🖥️

Direct Server Ports

48x GE access ports per chassis for direct server connections: IPS Mgmt (254), Wireless Guest (253), FortiGate (252), DMZ (292), etc.
