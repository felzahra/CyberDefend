Access Control Lists

Control network traffic flow by creating rules that permit or deny packets based on source/destination IP, protocol, and ports.

Step 01

ACL Concepts

Understand the two main types of ACLs and the golden rules for placing them on the network.

Standard vs. Extended

Standard ACL (1-99): Only looks at the Source IP. Place it as close to the destination as possible.
Extended ACL (100-199): Looks at Source, Destination, Protocol, and Port. Place it as close to the source as possible.

acl-rules.txt
/* Standard ACL Rule */ Source: 192.168.1.0/24 -> Destination: 10.0.0.0/8 Action: Apply Standard ACL on R2 (Destination side) to block 192.168.1.0 from reaching 10.0.0.0 /* Extended ACL Rule */ Source: 192.168.1.0/24 -> Destination: 10.0.0.1 (Web Server) Action: Apply Extended ACL on R1 (Source side) to block 192.168.1.0 from reaching 10.0.0.1 port 80
Network Traffic Filtering Infrastructure
Step 02

Standard ACL Configuration

Block the Sales VLAN (192.168.1.0/24) from reaching the IT VLAN (10.0.0.0/24), but allow all other traffic.

Create and Apply Standard ACL

Use wildcard mask 0.0.0.255 to match the /24 subnet. Apply it OUTBOUND on the interface connected to the IT VLAN.

standard-acl.conf
! 1. Create Standard ACL 10 R2(config)# access-list 10 deny 192.168.1.0 0.0.0.255 ! 2. Allow all other traffic (Implicit deny is at the bottom of every ACL) R2(config)# access-list 10 permit any ! 3. Apply to the IT VLAN interface (Outbound) R2(config)# interface gigabitEthernet 0/0 R2(config-if)# ip access-group 10 out R2(config-if)# exit
Step 03

Extended ACL Configuration

Block Sales VLAN (192.168.1.0/24) from accessing the Web Server (10.0.0.1) via HTTP (Port 80), but allow ICMP (ping) and all other traffic.

Create and Apply Extended ACL

Extended ACLs allow granular control. Protocol is 'tcp', destination port is 'eq 80'.

extended-acl.conf
! 1. Create Extended ACL 101 R1(config)# access-list 101 deny tcp 192.168.1.0 0.0.0.255 host 10.0.0.1 eq 80 ! 2. Allow all other IP traffic R1(config)# access-list 101 permit ip any any ! 3. Apply to the Sales interface (Inbound - closest to source) R1(config)# interface gigabitEthernet 0/0 R1(config-if)# ip access-group 101 in R1(config-if)# exit
Advanced Packet Inspection Configuration
Step 04

Named ACLs

Named ACLs are the modern best practice. They are easier to read and allow you to insert or delete specific lines without rewriting the whole list.

Standard Named ACL

named-acl.conf
! Create Extended Named ACL "BLOCK_HTTP" R1(config)# ip access-list extended BLOCK_HTTP ! Deny HTTP traffic to 10.0.0.1 R1(config-ext-nacl)# deny tcp any host 10.0.0.1 eq 80 ! Permit everything else R1(config-ext-nacl)# permit ip any any R1(config-ext-nacl)# exit ! Apply the named ACL R1(config)# interface gigabitEthernet 0/1 R1(config-if)# ip access-group BLOCK_HTTP in ! To ADD a line later without deleting the ACL: R1(config)# ip access-list extended BLOCK_HTTP R1(config-ext-nacl)# 15 deny tcp any host 10.0.0.2 eq 443
Step 05

Verification

Verify your ACL configuration and check how many packets have matched each rule.

verify-acl.conf
R1# show access-lists Standard IP access list 10 10 deny 192.168.1.0 0.0.0.255 (15 matches) 20 permit any (45 matches) Extended IP access list BLOCK_HTTP 10 deny tcp any host 10.0.0.1 eq www (8 matches) 15 deny tcp any host 10.0.0.2 eq 443 20 permit ip any any (30 matches) R1# show ip interface gigabitEthernet 0/1 Inbound access list is BLOCK_HTTP Outbound access list is not set

All ACL Commands

Complete cheat sheet for Standard, Extended, and Named ACL configuration.

CommandDescriptionMode
access-list [1-99] deny [source_ip] [wildcard]Create Standard ACL rule to block source networkGlobal Config
access-list [1-99] permit anyAllow all other traffic (Required to prevent implicit Deny)Global Config
access-list [100-199] deny tcp [src] [wildcard] [dest] [wildcard] eq [port]Create Extended ACL rule to block specific port (e.g., 80 for HTTP)Global Config
access-list [100-199] permit ip any anyAllow all other IP traffic in Extended ACLGlobal Config
ip access-list [standard|extended] [name]Create a Named ACL and enter ACL config modeGlobal Config
[sequence_num] deny tcp any host [ip] eq [port]Insert a specific rule at a sequence number in a Named ACLNamed ACL Config
ip access-group [id|name] [in|out]Apply ACL to an interface (Inbound or Outbound traffic)Interface Config
show access-listsView all ACLs configured on the router and match countsPrivileged EXEC
show ip interface [int]Verify which ACLs are applied to an interfacePrivileged EXEC
no access-list [id|name]Delete an entire ACL from the routerGlobal Config
