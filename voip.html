VoIP - Voice VLAN

Configure Cisco Catalyst switches to support IP Phones using Voice VLANs, PoE, QoS, and DHCP Option 150 for TFTP provisioning.

Step 01

Voice VLAN Configuration

IP Phones typically have a built-in switch. The PC plugs into the phone, and the phone plugs into the network switch. We separate voice and data traffic using different VLANs on the same port.

Switch Access Port Config

VLAN 10 is for Data (PC), and VLAN 110 is for Voice (Phone). CDP must be enabled to allow Cisco phones to discover the Voice VLAN.

voice-vlan.conf
! Enable CDP globally (Required for Cisco Phones) SW1(config)# cdp run ! Configure the interface connected to the IP Phone SW1(config)# interface gigabitEthernet 0/1 SW1(config-if)# switchport mode access SW1(config-if)# switchport access vlan 10 SW1(config-if)# switchport voice vlan 110 SW1(config-if)# spanning-tree portfast SW1(config-if)# exit
IP Phone connected to Cisco Switch
Step 02

Power over Ethernet (PoE)

PoE allows the switch to deliver electrical power to the IP Phone over the same Ethernet cable used for data. Catalyst switches can automatically negotiate power requirements.

poe-config.conf
SW1(config)# interface gigabitEthernet 0/1 ! Auto-negotiate PoE power (Default behavior) SW1(config-if)# power inline auto ! Alternatively, set a static power limit (e.g., 15.4 Watts for 802.3af) SW1(config-if)# power inline static max 15400 ! View PoE status and power consumption SW1# show power inline
Step 03

DSL Integration & QoS

When sending Voice Traffic over a slow DSL uplink, QoS is mandatory to prioritize voice packets over bulk data downloads. PPPoE is commonly used, requiring a lower MTU (1492).

Router DSL & QoS Config

dsl-qos.conf
! Configure PPPoE Dialer interface for DSL R1(config)# interface dialer 0 R1(config-if)# ip address negotiated R1(config-if)# mtu 1492 R1(config-if)# encapsulation ppp R1(config-if)# dialer pool 1 R1(config-if)# ppp authentication chap callin R1(config-if)# exit ! QoS: Priority Queue for Voice (DSCP EF - Expedited Forwarding) R1(config)# class-map match-any VOICE R1(config-cmap)# match protocol rtp R1(config-cmap)# exit R1(config)# policy-map VOICE_QOS R1(config-pmap)# class VOICE R1(config-pmap-c)# priority percent 30 ! Reserve 30% of bandwidth R1(config-pmap-c)# exit ! Apply QoS to the DSL Dialer interface R1(config)# interface dialer 0 R1(config-if)# service-policy output VOICE_QOS
Router managing VoIP over DSL uplink
Step 04

DHCP Option 150 (TFTP)

Cisco IP Phones download their configuration files from a TFTP server (usually the Cisco Unified Communications Manager - CUCM). Option 150 tells the phone where the TFTP server is.

Router DHCP Configuration

dhcp-voip.conf
R1(config)# ip dhcp excluded-address 192.168.110.1 192.168.110.10 R1(config)# ip dhcp pool VOICE_POOL R1(dhcp-config)# network 192.168.110.0 255.255.255.0 R1(dhcp-config)# default-router 192.168.110.1 ! Crucial: Define the TFTP Server IP (Option 150) R1(dhcp-config)# option 150 ip 10.0.0.5 R1(dhcp-config)# exit
