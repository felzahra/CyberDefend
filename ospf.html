OSPF Single Area

Configure Open Shortest Path First (OSPFv2) in a single Area 0 to dynamically route traffic between networks.

Step 01

Enable OSPF & Set Router ID

Start the OSPF process using a local Process ID (locally significant only). Then, manually set the Router ID to identify this router in the OSPF domain.

R1 Configuration

Best practice is to use a Loopback interface IP or manually assign the Router ID to ensure stability during interface failures.

ospf-process.conf
! Start OSPF process 10 (Local Process ID) R1(config)# router ospf 10 ! Manually set the Router ID (Format: X.X.X.X) R1(config-router)# router-id 1.1.1.1 R1(config-router)# exit
OSPF Link-State Router Network
Step 02

Configure Network Statements

Tell OSPF which interfaces should participate in OSPF and which area they belong to. Use wildcard masks instead of standard subnet masks.

R1 Interfaces & Wildcards

R1 has a LAN (192.168.1.0/24) and a WAN link (10.0.0.0/30). Both are assigned to Area 0 (Backbone).

ospf-networks.conf
R1(config)# router ospf 10 ! Add LAN interface (192.168.1.0/24 -> Wildcard 0.0.0.255) to Area 0 R1(config-router)# network 192.168.1.0 0.0.0.255 area 0 ! Add WAN interface (10.0.0.0/30 -> Wildcard 0.0.0.3) to Area 0 R1(config-router)# network 10.0.0.0 0.0.0.3 area 0 R1(config-router)# exit ! Note: R2 must be configured identically with its own IPs in Area 0. ! R2(config-router)# network 192.168.2.0 0.0.0.255 area 0 ! R2(config-router)# network 10.0.0.0 0.0.0.3 area 0
Step 03

Configure Passive Interfaces

OSPF sends Hello packets out all OSPF-enabled interfaces. You should make LAN interfaces passive to stop Hello packets from being sent to end-user PCs, which saves CPU and improves security.

passive-int.conf
R1(config)# router ospf 10 ! Make the LAN interface passive (Keeps adjacency on WAN, silences LAN) R1(config-router)# passive-interface gigabitEthernet 0/0 ! Alternatively, make ALL interfaces passive, then un-passive the WAN link R1(config-router)# passive-interface default R1(config-router)# no passive-interface serial 0/0/0 R1(config-router)# exit
Securing OSPF Router Interfaces
Step 04

Verify OSPF Neighbors & Routes

Verify that routers have formed a FULL adjacency and that OSPF routes (designated by 'O') are populating the routing table.

verify-ospf.conf
R1# show ip ospf neighbor Neighbor ID Pri State Dead Time Address Interface 2.2.2.2 1 FULL/BDR 00:00:33 10.0.0.2 Serial0/0/0 ! FULL state means the adjacency is established and LSDBs are synced. R1# show ip route ospf Codes: L - local, C - connected, S - static, O - OSPF O 192.168.2.0/24 [110/65] via 10.0.0.2, 00:01:15, Serial0/0/0 ! The 'O' represents a route learned dynamically via OSPF. R1# show ip protocols *** IP Routing is NSF aware *** Routing Protocol is "ospf 10" Outgoing update filter list for all interfaces is not set Incoming update filter list for all interfaces is not set Router ID 1.1.1.1 Number of areas in this router is 1. 1 normal 0 stub 0 nssa Maximum path: 4 Routing for Networks: 192.168.1.0 0.0.0.255 area 0 10.0.0.0 0.0.0.3 area 0
Reference

All OSPF Commands

Complete cheat sheet for OSPFv2 Single Area configuration, passive interfaces, and verification.

CommandDescriptionMode
router ospf [process-id]Enable OSPF routing process (Process ID is local only)Global Config
router-id [ip]Manually set the unique OSPF Router IDRouter Config
network [ip] [wildcard] area [id]Enable OSPF on interfaces in the specified subnet and assign to an AreaRouter Config
passive-interface [int]Stop sending OSPF Hello packets out of a specific interfaceRouter Config
passive-interface defaultMake ALL interfaces passive by defaultRouter Config
no passive-interface [int]Re-enable OSPF Hellos on a specific interface (usually WAN links)Router Config
auto-cost reference-bandwidth [mbps]Change default OSPF cost metric for high-speed links (e.g., 1000 for Gigabit)Router Config
show ip ospf neighborView OSPF neighbor adjacencies and their states (FULL, BDR, DR)Privileged EXEC
show ip route ospfView only routes learned dynamically via OSPF (marked with 'O')Privileged EXEC
show ip protocolsView active routing protocols, Router ID, and networksPrivileged EXEC
show ip ospf interface [int]View detailed OSPF settings (Cost, Timers, DR/BDR) for an interfacePrivileged EXEC
clear ip ospf processReset the OSPF process (required if changing the Router ID manually)Privileged EXEC
