Install Palo Alto Firewall (PA-VM)

Step-by-step guide to deploying Palo Alto Networks VM-Series Firewall in EVE-NG or GNS3.

1
Download the PA-VM Image

Download the Palo Alto VM (PA-VM-QEMU) image. You need a Palo Alto support account to download the official image. For lab purposes, PA-VM-9.x or 10.x is recommended. The file will be a .tgz archive. Extract it to get the .qcow2 file.

2
Add Image to EVE-NG

Upload the extracted QEMU image to your EVE-NG server using WinSCP or FileZilla.

# Create directory for Palo Alto in EVE-NG
mkdir /opt/unetlab/addons/qemu/paloalto-10.0
# Upload the qcow2 file to this directory via WinSCP
# Rename the file to 'hda.qcow2'
mv PA-VM-10.0.0.qcow2 /opt/unetlab/addons/qemu/paloalto-10.0/hda.qcow2
# Fix permissions
/opt/unetlab/wrappers/unl_wrapper -a fixpermissions

3
Add Image to GNS3 (Alternative)

Open GNS3 > Edit > Preferences > QEMU > QEMU VMs > New. Name it "PA-VM". Select "Qemu x86_64". Allocate at least 4096 MB RAM. Under Disk Image, browse for your .qcow2 file.

4
Initial Console Configuration

Boot up the PA-VM in your simulator. Open the console. Default credentials are admin / admin. Type configure to enter config mode.

configure
# Set hostname
set deviceconfig system hostname PA-FW-01
# Set management IP address
set deviceconfig system ip-address 192.168.1.10
set deviceconfig system netmask 255.255.255.0
set deviceconfig system default-gateway 192.168.1.1
# Set DNS servers
set deviceconfig system dns-primary 8.8.8.8
# Commit changes
commit
Access WebGUI: Once committed, you can access the WebGUI by navigating to https://192.168.1.10 from your browser. Default WebGUI login is admin / admin.
