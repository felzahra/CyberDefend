📚 Cybersecurity Threats in OSI Model

A comprehensive mapping of attack vectors to each layer. | By Dan Nanni · study-notes.org
OSI Layer ⚙️ Functions 🥷 Attack Vectors
Application Layer (Layer 7) User interface & app-level service, Web browsing, email, file transfer (HTTP, SMTP, DNS) 1. Malware injection
2. Phishing attacks
3. App-level DDoS attacks
Presentation Layer (Layer 6) Data encryption/decryption, compression, expansion, format conversion 1. Exploiting weak encryption
2. File format exploits
3. Malicious code injection
Session Layer (Layer 5) Create & terminate app sessions, session state, video conferencing 1. Session hijacking & replay
2. Session fixation attack
3. TLS/SSL renegotiation
Transport Layer (Layer 4) End-to-end data delivery, TCP/UDP protocols, error correction, congestion control 1. TCP/SYN & UDP flood attack
2. TCP hijacking & MITM
3. Port scan for vulnerability
Network Layer (Layer 3) Routing, IP addressing (IPv4/IPv6), packet filtering configuration 1. IP spoofing & fragmentation
2. Ping of death & ICMP flood
3. Route poisoning attacks
Data Link Layer (Layer 2) Frames, physical addressing, error detection, switching & VLAN configuration 1. ARP spoofing & poisoning
2. STP attack & MAC spoofing
3. Wireless vulnerability attacks
Physical Layer (Layer 1) Ethernet/fiber optic cabling, signaling, hardware configurations 1. Data interception & tampering
2. Signal jamming
3. Unauthorized device install

🌐 Types of Internet Threats

12 major categories of cyber threats. Think before you click.
Virus
Attaches to clean host files and replicates when executed.
Malware
Umbrella term for all intrusive or harmful software.
Spyware
Secretly monitors user activity, capturing keystrokes and data.
Adware
Delivers unwanted advertisements while tracking behavior.
Ransomware
Encrypts files and demands ransom payment for decryption key.
Trojan Horse
Disguised as legitimate software to deceive users into execution.
Worms
Self-replicating malware spreading across networks without interaction.
Phishing
Deceptive emails and websites engineered to steal credentials.
Botnet
Network of compromised devices controlled remotely for malicious tasks.
Rootkit
Hides malware deep inside OS kernel maintaining stealth access.
Keylogger
Records every hardware/software keystroke to steal input.
DDoS Attack
Overwhelms targets with traffic floods to exhaust availability.

🎯 Penetration Testing Fundamentals

Simulating cyberattacks to identify weaknesses before malicious actors exploit them.

Testing Methodologies

Black Box
Zero prior knowledge of IT infrastructure. Simulates external attacker.
Grey Box
Partial/limited knowledge of infrastructure (e.g., standard user credentials).
White Box
Full knowledge of infrastructure, internal access, source code, and configs.

Primary Scopes

Network Services
Infrastructure, switches, firewalls, routers, protocols, and ports.
Web Application
OWASP Top 10 vulnerabilities, API security, client-server setups.
Client Side
Software vulnerabilities on workstations (browsers, PDF readers, etc.).

⚡ Bug Bounty & Recon Cheatsheet

Essential Command-Line Tools & Usage Guides

1. Burp Suite

$ burpsuite # Launch GUI
$ burpsuite --project-file <file> # Specify project file
$ burpsuite --config-file <file> # Load specific config

2. Nuclei

$ nuclei -u https://target.com # Fast single scan
$ nuclei -l list.txt -t cves/ -severity high,critical # Scan list using template tags
$ nuclei -u https://target.com -o output.txt # Output results

3. Subfinder

$ subfinder -d example.com # Basic passive enumeration
$ subfinder -dL domains.txt -all -silent -oJ # Multi-domain JSON output

4. FFUF

$ ffuf -u https://target/FUZZ -w wordlist.txt # Basic fuzzing
$ ffuf -u https://target/FUZZ -w wordlist.txt -e .php,.bak -mc 200,302 # Match status codes

5. SQLmap

$ sqlmap -u "http://target/page.php?id=1" --batch # Automated default scan
$ sqlmap -u "http://target/page.php?id=1" --dbs # Enumerate databases
$ sqlmap -D appdb -T users --columns --dump # Extract target tables

6. OWASP Amass

$ amass enum -d example.com # Standard enumeration
$ amass enum -passive -d example.com # Passive subdomains
$ amass enum -brute -w wordlist.txt -d example.com # Brute force scan

7. HTTPX

$ cat hosts.txt | httpx # Probe live HTTP hosts
$ httpx -l hosts.txt -status-code -title -ip -tech-detect # Extract titles & technologies

8. Katana

$ katana -u https://example.com # Web crawling engine
$ katana -u https://example.com -d 2 -jc # Depth 2 + JS file parsing

🦠 Types of Malware

MALicious softWARE — threats that harm systems, steal data, or disrupt operations.
Virus
Attaches to files and spreads upon execution. (Examples: Melissa, CIH)
Worm
Self-replicates across network pathways without user intervention. (Conficker, Stuxnet)
Trojan
Disguised as beneficial software to trick users. (Zeus, Emotet)
Ransomware
Encrypts files and holds keys for extortion payment. (WannaCry, Ryuk)
Spyware
Secretly monitors user activity without consent. (CoolWebSearch, FinFisher)
Rootkit
Hides malware deep inside operating system kernel. (TDSS, ZeroAccess)
Keylogger
Records keystrokes to harvest passwords and sensitive input.
Botnet
Remotely controlled network of compromised devices. (Mirai)
