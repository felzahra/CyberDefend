Fortigate 🏡 Lab

In this article, we will play with Fortigate firewall 🙃 … I will use the Fortigate’s vm image ( link 🧝 at the end) and run it on VMware Workstation, you can also test it on GNS3.

Deploying the VM

Download the files and then right-click the “FortiGate-VM64” ( legends say it is more stable ) and open it with VMware Workstation.

Figure 1

Accept the terms of the licence agreement, then hit the Next button…

Figure 2

Change the VM’s name or its location if necessary and click Import …

Figure 3

Initial configuration

Launch the Fortigate VM and wait 😴 until boot is over …
default login is “ admin ” without a password.

Follow these commands to configure the WAN interface (port1)

config system interface edit port1 set ip 192.168.1.205 255.255.255.0 set allowaccess ssh ping http end (This command will save your configuration)
Figure 4 (Click on image to enlarge)

Then configure the default gateway ( your home router, in my case it is 192.168.1.1 ), using these commands …

conf router static edit 1 set device port1 set gateway 192.168.1.1 end (Don't forget to save your work)

LAN configuration (Firewall)

In VMware right-click on FortiGate-VM64, select one of the interfaces that you will use as a LAN gateway and then click on “LAN Segments…” > Add name it and click Ok.

Select “LAN segment” and chose the one you created. Click ok.
