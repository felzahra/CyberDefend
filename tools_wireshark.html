Wireshark Analysis

Capture and analyze network packets to detect attacks or troubleshoot configurations.

1
Start Capture

Open Wireshark on Kali Linux. Double-click eth0 to start capturing traffic on your primary interface.

2
Display Filters

Use filters to isolate specific traffic types.

# Filter by IP address
ip.addr == 192.168.1.10

# Filter by HTTP traffic
http

# Filter by ARP (Useful for MITM detection)
arp

# Filter by DNS
dns

3
Extracting Credentials (HTTP)

If a victim logs into an unencrypted HTTP site, you can extract their password.

  1. Filter by http.request.method == "POST"
  2. Right-click the POST packet > Follow > TCP Stream
  3. Look for username=admin&password=Password123 in the stream data.
Tip: Wireshark is pre-installed on Kali Linux. You can launch it from the terminal by typing wireshark &.
