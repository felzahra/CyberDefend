Install Cisco IOS Images

Setup Cisco Routers (Dynamips) and Switches (IOL/vIOS) for your network topology.

1
Cisco IOS Routers (c7200)

Download the c7200-adventerprisek9-mz.152-4.M2.bin image. In EVE-NG, place it in the Dynamips directory.

mkdir /opt/unetlab/addons/dynamips/
# Upload the .bin file via WinSCP to this directory
/opt/unetlab/wrappers/unl_wrapper -a fixpermissions

2
Cisco IOL Switches (L2/L3)

Cisco IOL (IOS on Linux) is used for multilayer switches (like c3745 or generic L2 switches). In EVE-NG, place the binary files in the IOL directory.

mkdir /opt/unetlab/addons/iol/bin/
# Upload files like 'i86bi-linux-l2-adventerprisek9-mz.SSA.highiron.bin'
# Create a license file:
echo "127.0.0.127" > /opt/unetlab/addons/iol/bin/iourc
/opt/unetlab/wrappers/unl_wrapper -a fixpermissions

3
Add Image to GNS3

Open GNS3 > Preferences > IOS routers > New. Select the .bin image. GNS3 will automatically suggest an idle-PC value. Set it to 128 MB RAM. For switches, use the "IOS on UNIX (IOL)" option in GNS3.

Warning: Downloading Cisco IOS images from third-party sites may violate Cisco EULA. Always use a valid VIRL/CML account if available.
