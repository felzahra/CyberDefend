Switch Management

A complete reference guide covering Console, SSH, HTTPS, RBAC, Passwords, L2/L3 configuration, ACLs, and Scheduled Tasks.

Step 01

Console & Access Modes

Understand the different CLI modes. User EXEC is read-only, Privileged EXEC allows viewing configs, and Global Config allows making changes.

Securing the Console Port

The console port is physical access. It must be secured first.

console-config.conf
Switch(config)# line console 0 Switch(config-line)# password cisco123 Switch(config-line)# login Switch(config-line)# exit ! Privilege Levels (0-15). Level 15 is full access. Switch(config)# enable secret class12345 Switch(config)# service password-encryption
Physical Console Port Management
Step 02

Passwords & RBAC

Role-Based Access Control (RBAC) allows you to create specific user accounts with limited privileges, rather than sharing the full enable password.

Local Users & Privilege Levels

Create a read-only user (Level 5) and an admin user (Level 15).

rbac-config.conf
! Create Admin User (Full Access) Switch(config)# username admin privilege 15 secret admin_pass_123 ! Create Read-Only User (Can only run 'show' commands) Switch(config)# username tech privilege 5 secret tech_pass_123 ! Define what Level 5 can do (e.g., allow 'show running-config') Switch(config)# privilege exec level 5 show running-config ! Tell VTY/Console lines to use the local database Switch(config)# line vty 0 15 Switch(config-line)# login local
Step 03

Telnet & SSH Configuration

Telnet is insecure (plaintext). SSH encrypts all traffic. Always disable Telnet and use SSH version 2.

ssh-vty.conf
! 1. Required for SSH: Hostname and Domain Name Switch(config)# hostname SW1 SW1(config)# ip domain-name cyberdefend.local ! 2. Generate RSA Keys (1024 or 2048 bits) SW1(config)# crypto key generate rsa ! 3. Force SSH Version 2 SW1(config)# ip ssh version 2 ! 4. Secure VTY Lines (Disable Telnet, Allow SSH) SW1(config)# line vty 0 15 SW1(config-line)# transport input ssh SW1(config-line)# login local SW1(config-line)# exit
Step 04

HTTPS Web GUI

Enable the web GUI for easier management. Ensure HTTPS is used so credentials are encrypted.

Securing Web Access

https-config.conf
! 1. Disable HTTP (Insecure) SW1(config)# no ip http server ! 2. Enable HTTPS Secure Server SW1(config)# ip http secure-server ! 3. Use local database for Web Authentication SW1(config)# ip http authentication local ! Access via browser: https://[Switch_IP]
Web-Based Network Management
Step 05

L2/L3, VLANs & ROAS

Managing Layer 2 (VLANs) and Layer 3 (Routing). Use SVIs for L3 switches, or Router-on-a-Stick (ROAS) for L2 switches.

SVI (Layer 3 Switch) vs ROAS (Layer 2 Switch)

l2-l3-config.conf
! --- LAYER 2: Create VLANs --- SW1(config)# vlan 10 SW1(config-vlan)# name SALES SW1(config-vlan)# exit ! --- LAYER 3 (SVI on Core Switch) --- SW1(config)# ip routing SW1(config)# interface vlan 10 SW1(config-if)# ip address 192.168.10.1 255.255.255.0 SW1(config-if)# no shutdown ! --- ALTERNATIVE: ROAS (On a Router connected to Trunk) --- Router(config)# interface gigabitEthernet 0/0.10 Router(config-subif)# encapsulation dot1Q 10 Router(config-subif)# ip address 192.168.10.1 255.255.255.0
Step 06

ACLs for Management Security

Restrict SSH/HTTPS access so only specific Admin PCs can manage the switch.

VTY Access Control List

mgmt-acl.conf
! 1. Create ACL allowing only Admin IP (10.0.0.5) SW1(config)# access-list 10 permit host 10.0.0.5 ! 2. Apply ACL to VTY lines SW1(config)# line vty 0 15 SW1(config-line)# access-class 10 in ! 3. Apply ACL to HTTPS Web Server SW1(config)# ip http access-class 10
Step 07

Scheduled Tasks (Kron)

Automate repetitive tasks like saving the configuration every night using the Kron scheduler.

Auto-Save Configuration

kron-tasks.conf
! 1. Create a Kron Policy SW1(config)# kron policy-list SAVE_CONFIG SW1(config-kron-policy)# cli write memory SW1(config-kron-policy)# exit ! 2. Schedule the Policy to run at 02:00 AM daily SW1(config)# kron occurrence DAILY_SAVE at 02:00 recurring SW1(config-kron-occurrence)# policy-list SAVE_CONFIG SW1(config-kron-occurrence)# exit
