1. Installation on EVE-NG / GNS3Setting up PA-VM QEMU Image

1
Download the PA-VM Image
Download the Palo Alto VM (PA-VM-QEMU) image from the Palo Alto support portal or authorized sources.
ℹ️
You need an account to download the official image. For labs, PA-VM-9.x or 10.x is recommended. Extract the .qcow2 file from the downloaded .tgz archive.
2
Add Image to EVE-NG / GNS3
Place the extracted QEMU image into the EVE-NG Linux directory.
LINUX CLI (EVE-NG)
# Create directory for Palo Alto in EVE-NG
mkdir /opt/unetlab/addons/qemu/paloalto-10.0
# Upload the qcow2 file to this directory via WinSCP or FileZilla
# Rename the file to 'hda.qcow2'
mv PA-VM-10.0.0.qcow2 /opt/unetlab/addons/qemu/paloalto-10.0/hda.qcow2
# Fix permissions
/opt/unetlab/wrappers/unl_wrapper -a fixpermissions
⌨️

2. Initial CLI ConfigurationConsole setup

Boot up the PA-VM in EVE-NG. Open the console. Default credentials are admin / admin.

PALO ALTO CLI
configure
# Set hostname
set deviceconfig system hostname PA-FW-01
# Set management IP address
set deviceconfig system ip-address 192.168.1.10
set deviceconfig system netmask 255.255.255.0
set deviceconfig system default-gateway 192.168.1.1
# Set DNS servers
set deviceconfig system dns-primary 8.8.8.8
# Commit changes
commit
💡
Once committed, you can access the WebGUI by navigating to https://192.168.1.10 from your browser.
🔌

3. Network Interfaces & ZonesLayer 3 configuration

1
Configure Physical Interfaces
Assign IP addresses to ethernet1/1 (Trust) and ethernet1/2 (Untrust).
CLI CONFIGURATION
# Trust Interface (LAN)
set network interface ethernet ethernet1/1 layer3 ip 10.0.0.1/24
set network interface ethernet ethernet1/1 comment Trust-LAN

# Untrust Interface (WAN)
set network interface ethernet ethernet1/2 layer3 ip 203.0.113.2/30
set network interface ethernet ethernet1/2 comment Untrust-WAN
2
Create Zones
Bind interfaces to security zones.
CLI CONFIGURATION
# Trust Zone
set zone Trust network layer3 ethernet1/1
set zone Trust enable-user-identification yes

# Untrust Zone
set zone Untrust network layer3 ethernet1/2
🛤️

4. Virtual Router & Static RoutesDefault route to ISP

CLI CONFIGURATION
# Add interfaces to Virtual Router
set network virtual-router default interface ethernet1/1
set network virtual-router default interface ethernet1/2

# Create Default Route (0.0.0.0/0) pointing to ISP Gateway
set network virtual-router default routing-table ip static-route Default-Route destination 0.0.0.0/0
set network virtual-router default routing-table ip static-route Default-Route nexthop ip-address 203.0.113.1
🛡️

5. Security Policies (Allow / Deny)Permit internal traffic, block inbound

1
Allow Web Traffic Outbound (Trust to Untrust)
Permit HTTP, HTTPS, and DNS from the LAN to the Internet.
CLI CONFIGURATION
set rulebase security rules Allow-Outbound-Web
    from Trust
    to Untrust
    source any
    destination any
    application [ web-browsing dns ssl ]
    service application-default
    action allow
2
Deny All Inbound (Untrust to Trust)
Default deny rule to block all unsolicited inbound traffic.
CLI CONFIGURATION
set rulebase security rules Deny-Inbound
    from Untrust
    to Trust
    source any
    destination any
    application any
    service any
    action deny
🌐

6. NAT PoliciesSource NAT for Internet Access

CLI CONFIGURATION
# Outbound Source NAT (Dynamic IP and Port)
set rulebase nat rules Outbound-NAT
    from Trust
    to Untrust
    source any
    destination any
    source-translation dynamic-ip-and-port
        translated-address interface-address
            interface ethernet1/2
            ip-address 203.0.113.2
✅

7. Commit & VerifyApply changes to running config

PALO ALTO CLI
# Save and apply all configurations
commit
# Verify routing table
show routing route
# Verify interface status
show interface all
⚠️
Warning: Palo Alto requires a commit for changes to take effect. If you don't commit, your interfaces and policies will not work!
