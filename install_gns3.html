⚠️ Which one should I choose?

GNS3: Easier to install and link to your local PC (Cloud node). Great for CCNA/CCNP routing.
EVE-NG (Recommended for this course): Much better performance for heavy QEMU images like Palo Alto and Fortinet. Stable topology management.

System Requirements

  • CPU: Intel i5 / AMD Ryzen 5 or better (Virtualization VT-x/AMD-V MUST be enabled in BIOS).
  • RAM: Minimum 16GB (32GB recommended to run multiple firewalls).
  • Storage: 100GB free SSD space (HDD will work but labs will boot slowly).
  • OS: Windows 10/11, macOS, or Linux.
  • Hypervisor: VMware Workstation Player (Free) or VirtualBox (Free).

Option 1: Installing EVE-NG (Recommended)

1

Download EVE-NG OVA

Download the EVE-NG Community Edition OVA file from the official website.

Download EVE-NG CE
2

Import to VMware / VirtualBox

Double-click the downloaded .ova file. VMware will open. Adjust the RAM to 8GB (8192 MB) and CPU to 4 cores before importing.

💡 Network Adapter: In VMware, set the Network Adapter to "Bridged" so your EVE-NG gets an IP on your local network.
3

Access EVE-NG Web Interface

Start the VM. When it boots, it will display an IP address on the screen (e.g., 192.168.1.50). Open a browser on your PC and go to http://192.168.1.50.

Default Login: admin / eve

4

Upload Images via WinSCP

To add Palo Alto, Fortinet, or Cisco images, use WinSCP to connect to the EVE-NG IP using SFTP.

# Directory paths in EVE-NG for different images:
/opt/unetlab/addons/qemu/      # For Firewalls (PA, Fortinet, Kali)
/opt/unetlab/addons/dynamips/  # For Cisco IOS routers (c7200)
/opt/unetlab/addons/iol/bin/   # For Cisco L2/L3 switches (IOL)

Make sure to fix permissions after uploading via the EVE-NG CLI:

/opt/unetlab/wrappers/unl_wrapper -a fixpermissions

Option 2: Installing GNS3

1

Download GNS3

Download the GNS3 All-in-One installer for Windows/Mac.

Download GNS3
2

Install GNS3 VM

During installation, check the box to install GNS3 VM. This requires VMware or VirtualBox to be installed first. The GNS3 VM offloads the CPU processing of routers/firewalls from your Windows OS.

3

Import QEMU Images (Firewalls)

Open GNS3 > Edit > Preferences > QEMU > QEMU VMs. Click "New" to import your Palo Alto and Fortinet .qcow2 or .raw files.

⚠️ Note: GNS3 can be finicky with Palo Alto. Ensure you allocate at least 4096 MB of RAM to the PA-VM in GNS3 preferences.

Connecting Kali Linux to the Lab

You do not need to run Kali inside GNS3/EVE-NG. It's better to run Kali as a separate VM in VMware/VirtualBox and connect it to your virtual network.

  1. Download the Kali Linux VM image.
  2. In GNS3, drag a "Cloud" node to the workspace.
  3. Right-click the Cloud > Configure. Under "Ethernet Interfaces", select your VMware Virtual Adapter (e.g., VMnet1 or VMnet8).
  4. Connect the Cloud node to your Switch/Router in the topology.
  5. In Kali Linux, ensure the network adapter is set to the same VMnet.
