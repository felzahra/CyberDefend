Welcome to the CyberDefend Hub

Select a lab or tool from the left panel to begin your training. Start with the installations if you are setting up your environment for the first time.

Step 1: Install Lab

Install GNS3 or EVE-NG, then load your firewall and router images. Click "Install GNS3" to begin.

Step 2: Build Topology

Drag and drop devices to build the enterprise network topology (Access, Dist, Core, FW).

Step 3: Execute Attacks

Use Kali Linux to launch simulated attacks against your network infrastructure.

Step 4: Mitigate

Configure Palo Alto and Fortinet firewalls to detect and block the attacks.

Frequently Asked Questions

Where do I start?
If you are new to network labs, start with the "Install GNS3 & EVE-NG" link in the left panel. Once your simulator is running, proceed to install the firewall images (Palo Alto, Fortinet).
How do I simulate an attack?
Navigate to the "Attack Labs" section in the left panel. Each lab contains step-by-step instructions on how to use tools like Kali Linux, Nmap, and Metasploit to simulate the attack.
What if the page is blank when I click a link?
The hub loads separate HTML files. Ensure that the files (e.g., install_gns3.html) exist in the same directory structure as this main page.
