Install Fortinet Firewall (FortiGate)

Deploy the FortiGate VM in EVE-NG or GNS3 for edge security and UTM configuration.

1
Download FortiGate VM

Download the FortiGate-VM QEMU image (.qcow2) from the Fortinet Support portal. Usually, you want the 64-bit v7.0 or v7.2 version.

2
Add Image to EVE-NG

mkdir /opt/unetlab/addons/qemu/fortinet-7.2
# Upload the qcow2 file to this directory via WinSCP
# Rename the file to 'fortios.qcow2'
mv FGVM64.qcow2 /opt/unetlab/addons/qemu/fortinet-7.2/fortios.qcow2
/opt/unetlab/wrappers/unl_wrapper -a fixpermissions

3
Initial Console Configuration

Boot the FortiGate VM. Open the console. Default credentials are admin / (no password). You will be forced to change the password on first login.

# Configure Port1 as Management Interface
config system interface
    edit port1
        set ip 192.168.1.99 255.255.255.0
        set allowaccess ping https ssh
    next
end

# Set Default Gateway
config router static
    edit 1
        set device port1
        set dst 0.0.0.0 0.0.0.0
        set gateway 192.168.1.1
    next
end
Access WebGUI: Open your browser and navigate to https://192.168.1.99. Log in with admin and your new password.
