1. Introduction to Nessus

Nessus is a widely-used vulnerability scanner developed by Tenable Network Security. It helps security professionals identify vulnerabilities, misconfigurations, and security issues in their IT infrastructure.

Key Features

  • Comprehensive plugin-based scanning with frequent updates
  • Detailed vulnerability reports with remediation guidance
  • Customizable scan policies and templates
  • Support for network, cloud, and container environments

2. Installation & Setup

1

Download Nessus

Visit the Tenable website and download the appropriate Nessus version for your operating system.

2

Install Nessus

Run the installer and follow the installation wizard.

# For Debian/Ubuntu sudo dpkg -i Nessus-x.x.x-debian6_amd64.deb # For RHEL/CentOS sudo rpm -ivh Nessus-x.x.x-es7.x86_64.rpm
3

Activate Nessus

Navigate to https://localhost:8834 to access the web interface. Create an admin account and activate using your code.

4

Initialize Plugins

Nessus will download and compile plugins. This may take several minutes.

3. Scan Configuration

1

Access Scans Menu

From the main dashboard, click on "Scans" in the top navigation menu, then click "New Scan".

2

Select Scan Template

Choose a scan template based on your assessment goals.

TemplateDescriptionUse Case

4. Launching a Scan

1

Save and Launch

After configuring your scan, click "Save" and then "Launch".

2

Monitor Progress

Monitor the scan progress from the Scans page to see status and completion percentage.

5. Analyzing Results

1

View Results

Click on the scan name to view detailed results and an overview of vulnerabilities by severity.

2

Examine Vulnerabilities

Click on a vulnerability to view detailed information including description, CVSS score, and solution.

7. Understanding CVSS Scores

The Common Vulnerability Scoring System (CVSS) provides a standardized way to assess the severity of security vulnerabilities (0 to 10).

CVSS Severity Ratings

Critical9.0 - 10.0
High7.0 - 8.9
Medium4.0 - 6.9
Low0.1 - 3.9
