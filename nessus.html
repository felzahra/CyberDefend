1. Introduction to Nessus

Nessus is a widely-used vulnerability scanner developed by Tenable Network Security. It helps security professionals identify vulnerabilities, misconfigurations, and security issues in their IT infrastructure. Nessus scans for:

Vulnerabilities

Software flaws that could be exploited by attackers to compromise systems.

Misconfigurations

Improper settings that could expose systems to unnecessary risk.

Malware

Detection of known malware on systems and networks.

Key Features
  • Comprehensive plugin-based scanning with frequent updates
  • Detailed vulnerability reports with remediation guidance
  • Customizable scan policies and templates
  • Support for network, cloud, and container environments

2. Installation & Setup

1

Download Nessus

Visit the Tenable website and download the appropriate Nessus version for your operating system.

2

Install Nessus

Run the installer and follow the installation wizard. For Windows, run the executable; for Linux, use your package manager.

# For Debian/Ubuntu sudo dpkg -i Nessus-x.x.x-debian6_amd64.deb # For RHEL/CentOS sudo rpm -ivh Nessus-x.x.x-es7.x86_64.rpm
3

Activate Nessus

Navigate to https://localhost:8834 to access the Nessus web interface. You'll need to create an admin account and activate using your activation code.

4

Initialize Plugins

Nessus will download and compile plugins. This process may take several minutes depending on your system and network speed.

3. Scan Configuration

1

Access Scans Menu

From the main dashboard, click on "Scans" in the top navigation menu, then click "New Scan" to create a new scan configuration.

2

Select Scan Template

Choose a scan template based on your assessment goals. Common templates include:

Template Description Use Case
Basic Network Scan Standard vulnerability scan General vulnerability assessment
Advanced Scan Highly configurable scan Custom vulnerability assessments
Credentialed Patch Audit Checks for missing patches Patch management verification
3

Configure Scan Settings

Enter scan details and target information (Name, Description, Targets: IP addresses, hostnames, or CIDR ranges).

4. Launching a Scan

1

Save and Launch

After configuring your scan, click "Save" and then "Launch" to start the scan.

2

Monitor Scan Progress

Monitor the scan progress from the Scans page. You can see the status, completion percentage, and time remaining.

5. Analyzing Results

1

View Scan Results

Once the scan completes, click on the scan name to view detailed results. The results dashboard provides an overview of vulnerabilities by severity.

2

Examine Individual Vulnerabilities

Click on a vulnerability to view detailed information including description, CVSS score, affected hosts, and solution.

6. Extracting CVEs from Scan Results

1

Identify CVE References

Within each vulnerability detail page, look for the "References" section which contains links to CVEs and other security advisories.

2

Export Results

To extract all CVEs at once, export the scan results in CSV or PDF format by clicking "Export" at the top of the results page.

3

Extract CVEs from CSV

If you exported as CSV, open the file in Excel and look for the "CVE" column. You can filter this column to get a list of all unique CVEs.

7. Understanding CVSS Scores

The Common Vulnerability Scoring System (CVSS) provides a standardized way to assess the severity of security vulnerabilities. Nessus displays CVSS scores for each vulnerability it identifies.

CVSS Severity Ratings

CVSS scores range from 0 to 10, with higher scores indicating more severe vulnerabilities:

  • Critical 9.0 - 10.0
  • High 7.0 - 8.9
  • Medium 4.0 - 6.9
  • Low 0.1 - 3.9

CVSS Vector Components

The CVSS vector string provides additional details about how the score was calculated. It includes metrics for Attack Vector (AV), Attack Complexity (AC), Privileges Required (PR), User Interaction (UI), Scope (S), Confidentiality (C), Integrity (I), and Availability (A).

8. Searching CVE Details in MITRE

1

Access MITRE CVE Database

Go to the MITRE CVE database at https://cve.mitre.org or the NVD at https://nvd.nist.gov.

2

Search for Specific CVE

Enter the CVE ID (e.g., CVE-2021-44228) extracted from Nessus into the search box and submit the search.

3

Review CVE Details

The CVE entry will display detailed information including description, affected products, references, and CVSS score.

4

Cross-Reference with NVD

For additional details, especially CVSS score breakdowns, cross-reference the CVE with the NVD (National Vulnerability Database).

9. Remediation Strategies

Patch Management

Apply security patches released by vendors to address identified vulnerabilities. Prioritize based on severity and system criticality.

Configuration Changes

Modify system configurations to reduce exposure, such as disabling unnecessary services, restricting access, or hardening settings.

Network Segmentation

Isolate critical systems or vulnerable services using network segmentation to limit potential attack paths.

Virtual Patching

Implement temporary security controls through WAF rules, IPS signatures, or other security tools while permanent fixes are developed.

10. Best Practices

Regular Scanning Schedule

Establish a regular scanning cadence based on risk:

  • External-facing systems: Weekly
  • Critical internal systems: Bi-weekly
  • Standard internal systems: Monthly
Credentialed Scanning

Enable authenticated scans for more comprehensive results:

  • Local credentials for systems
  • Domain credentials for Windows environments
  • SSH keys for Linux/Unix systems

Conclusion

Nessus provides a powerful platform for identifying and managing vulnerabilities in your environment. By following this guide, you can effectively scan for vulnerabilities, extract CVE information, understand CVSS scores, and research detailed vulnerability information in the MITRE CVE database.

Remember that vulnerability scanning is just one component of a comprehensive security program. Combine regular scanning with patch management, configuration hardening, and security awareness to build a robust defense against evolving threats.
