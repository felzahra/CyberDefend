Types of Cyber Attacks

A comprehensive guide to the most common and dangerous cyber attacks used by threat actors to compromise systems, networks, and individuals.

1. Malware Attacks

Malware (Malicious Software) is any code or program intentionally designed to cause damage, steal data, or gain unauthorized access to a system.

Ransomware

Malicious software that encrypts a victim's files and demands a cryptocurrency payment (ransom) in exchange for the decryption key. Paralyzes business operations.

Trojan Horse

Disguises itself as legitimate, harmless software to trick users into installing it. Once inside, it creates a backdoor for attackers to control the system.

Worm

A standalone malware program that self-replicates and spreads across networks without any user interaction, consuming bandwidth and dropping payloads.

2. Network & Infrastructure Attacks

Network attacks target the infrastructure, routing, and data in transit between devices. They aim to intercept, disrupt, or redirect communications.

DDoS Attack

Distributed Denial of Service. Attackers use thousands of infected devices (botnets) to flood a server with fake traffic until it crashes and becomes unavailable.

Man-in-the-Middle (MITM)

An attacker secretly intercepts and possibly alters communication between two parties who believe they are directly talking to each other.

DHCP Starvation & Rogue DHCP

An attacker floods the network's DHCP server with fake MAC addresses, exhausting its IP pool. They then introduce a "Rogue DHCP" server to hand out malicious IPs and gateways.

DNS Spoofing (Cache Poisoning)

Injecting malicious data into a DNS cache, causing users to be redirected from a legitimate website (like a bank) to a fake, attacker-controlled website.

DNS Tunneling

Encapsulating non-DNS traffic (like stolen data or command-and-control commands) inside DNS queries to bypass firewalls and steal data undetected.

3. Web Application Attacks

These attacks specifically target vulnerabilities in web applications, often manipulating input fields to access backend databases or steal user sessions.

SQL Injection (SQLi)

Inserting malicious SQL database commands into input fields (like login forms) to bypass authentication, dump the database, or delete data.

Cross-Site Scripting (XSS)

Injecting malicious JavaScript into a trusted website. When a victim visits the page, the script executes in their browser, stealing session cookies.

4. Wireless Attacks

Wireless networks (Wi-Fi) are inherently less secure than wired networks because data is broadcasted through the air. Attackers can intercept signals from a distance.

Evil Twin

An attacker sets up a fake Wi-Fi hotspot with the same name (SSID) as a legitimate one (e.g., "Starbucks_WiFi"). Victims connect to it, allowing the attacker to intercept all their traffic.

Deauthentication Attack

Sending forged "disconnect" packets to a victim's device, forcibly kicking them off a legitimate Wi-Fi network. Often used to force them to connect to an Evil Twin.

WPA/WPA2 Cracking

Capturing the 4-way handshake when a device connects to Wi-Fi, then using offline brute-force or dictionary attacks (like Aircrack-ng) to guess the network password.

5. Social Engineering Attacks

Instead of hacking systems, social engineering hacks the human mind. Attackers manipulate psychology to trick people into making security mistakes.

Phishing

Sending fraudulent emails that impersonate trusted brands or banks to trick victims into clicking malicious links and entering their passwords.

Spear Phishing

A highly targeted version of phishing aimed at a specific individual or organization, using personal details to appear highly convincing.
