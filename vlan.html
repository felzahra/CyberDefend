Basic VLAN Configuration

Learn how to create Virtual LANs (VLANs), assign ports, configure trunks, and route between them.

Step 01

Create VLANs

VLANs logically segment a physical network into multiple broadcast domains. First, create the VLANs and assign them names.

VLAN Database Configuration

By default, all ports are in VLAN 1. We will create VLAN 10 (Sales) and VLAN 20 (IT).

create-vlan.conf
SW1(config)# vlan 10 SW1(config-vlan)# name SALES SW1(config-vlan)# exit SW1(config)# vlan 20 SW1(config-vlan)# name IT SW1(config-vlan)# exit
Logical vs Physical Network Segmentation
Step 02

Assign Access Ports

Assign specific switch ports to the VLANs you created so end devices can communicate within their respective domains.

access-ports.conf
! Assign Ports 1-5 to VLAN 10 SW1(config)# interface range gi0/1 - 5 SW1(config-if-range)# switchport mode access SW1(config-if-range)# switchport access vlan 10 SW1(config-if-range)# exit ! Assign Ports 6-10 to VLAN 20 SW1(config)# interface range gi0/6 - 10 SW1(config-if-range)# switchport mode access SW1(config-if-range)# switchport access vlan 20
Step 03

Configure Voice VLAN

IP Phones require a special Voice VLAN to keep voice traffic separate from data traffic on the same physical port.

voice-vlan.conf
! Configure port for PC (Data VLAN 10) + Phone (Voice VLAN 100) SW1(config)# interface gigabitEthernet 0/1 SW1(config-if)# switchport mode access SW1(config-if)# switchport access vlan 10 SW1(config-if)# switchport voice vlan 100 SW1(config-if)# spanning-tree portfast
Step 04

Configure Trunk Ports

Trunks allow multiple VLANs to travel over a single link between switches or from a switch to a router.

trunk-port.conf
SW1(config)# interface gigabitEthernet 0/24 SW1(config-if)# switchport mode trunk SW1(config-if)# switchport trunk allowed vlan 10,20,100
802.1Q Trunk Link Configuration
Step 05

Verify VLANs

Always verify your configuration to ensure VLANs and ports are assigned correctly.

verify-vlans.conf
SW1# show vlan brief VLAN Name Status Ports ---- -------------------------------- --------- ------------------------------- 1 default active Gi0/11, Gi0/12, Gi0/13 10 SALES active Gi0/1, Gi0/2, Gi0/3, Gi0/4, Gi0/5 20 IT active Gi0/6, Gi0/7, Gi0/8, Gi0/9, Gi0/10 100 VOICE active SW1# show interfaces trunk Port Mode Encapsulation Status Native vlan Gi0/24 trunk 802.1q trunking 1 Port Vlans allowed on trunk Gi0/24 10,20,100
Layer 3 Routing

Inter-VLAN Routing: Router-on-a-Stick

To allow VLAN 10 and VLAN 20 to talk to each other, configure sub-interfaces on a router connected to a switch trunk port.

Router Configuration

Configure 802.1Q encapsulation on the router interface for each VLAN.

router-on-a-stick.conf
Router(config)# interface gigabitEthernet 0/0 Router(config-if)# no shutdown ! Sub-interface for VLAN 10 Router(config)# interface gigabitEthernet 0/0.10 Router(config-subif)# encapsulation dot1Q 10 Router(config-subif)# ip address 192.168.10.1 255.255.255.0 ! Sub-interface for VLAN 20 Router(config)# interface gigabitEthernet 0/0.20 Router(config-subif)# encapsulation dot1Q 20 Router(config-subif)# ip address 192.168.20.1 255.255.255.0
Router-on-a-Stick Topology
Layer 3 Routing

Inter-VLAN Routing: L3 Switch SVI

For modern networks, use a Layer 3 switch with Switch Virtual Interfaces (SVIs) to route between VLANs at hardware speeds.

Layer 3 Switch Configuration

Enable IP routing globally, then assign an IP address to the VLAN interface.

l3-switch-svi.conf
! Enable Layer 3 routing globally on the switch SW1(config)# ip routing ! Configure SVI for VLAN 10 SW1(config)# interface vlan 10 SW1(config-if)# ip address 192.168.10.1 255.255.255.0 SW1(config-if)# no shutdown SW1(config-if)# exit ! Configure SVI for VLAN 20 SW1(config)# interface vlan 20 SW1(config-if)# ip address 192.168.20.1 255.255.255.0 SW1(config-if)# no shutdown
