Subnetting Practice

Master the math of networking. Learn to slice IPv4 and IPv6 networks using CIDR, VLSM, and Route Summarization.

Step 01

IPv4 Basics & CIDR

Classless Inter-Domain Routing (CIDR) replaced the old classful system (A, B, C). It uses a slash notation (e.g., /24) to define how many bits are used for the network portion.

Slicing a /24 Network

If you borrow 3 bits from the host portion, you create 2^3 = 8 subnets. Each subnet loses 2 IPs (Network and Broadcast).

cidr-math.txt
/* Base Network: 192.168.1.0/24 */ /* Requirement: Create 4 subnets */ Formula: 2^n = Subnets (n = borrowed bits) 2^n = 4 => n = 2 borrowed bits New Mask: 24 + 2 = /26 (255.255.255.192) Hosts per Subnet: 2^(8-2) - 2 = 62 usable hosts /* Resulting Subnets */ Subnet 1: 192.168.1.0/26 (Range: 1 - 62) Subnet 2: 192.168.1.64/26 (Range: 65 - 126) Subnet 3: 192.168.1.128/26 (Range: 129 - 190) Subnet 4: 192.168.1.192/26 (Range: 193 - 254)

Step 02

Variable Length Subnet Masking (VLSM)

VLSM allows you to use different subnet masks within the same network. This prevents wasting IP addresses by sizing the subnet precisely to the need of each link.

VLSM Design Scenario

Given 192.168.1.0/24, allocate subnets for: LAN A (50 hosts), LAN B (25 hosts), WAN Link (2 hosts).

vlsm-design.txt
/* Step 1: Sort requirements largest to smallest */ 1. LAN A: 50 hosts -> needs 64 block (/26) 2. LAN B: 25 hosts -> needs 32 block (/27) 3. WAN: 2 hosts -> needs 4 block (/30) /* Step 2: Allocate sequentially */ LAN A: 192.168.1.0/26 (Usable: .1 to .62) LAN B: 192.168.1.64/27 (Usable: .65 to .94) WAN: 192.168.1.96/30 (Usable: .97 to .98) /* Next available IP: 192.168.1.100 */
Step 03

IPv6 Subnetting

IPv6 is actually easier to subnet than IPv4. The standard LAN subnet is a /64. You subnet by borrowing bits from the 16-bit "Subnet ID" field.

Slicing a /48 Global Prefix

ISPs usually assign a /48 to enterprises. This leaves 16 bits for subnetting (creating 65,536 /64 subnets).

ipv6-subnet.txt
/* Base Prefix: 2001:db8:abcd::/48 */ /* Structure: [48-bit Global] [16-bit Subnet ID] [64-bit Interface ID] */ Subnet 1: 2001:db8:abcd:0000::/64 Subnet 2: 2001:db8:abcd:0001::/64 Subnet 3: 2001:db8:abcd:0002::/64 /* In Hex, 000A = 10 in decimal */ Subnet 11: 2001:db8:abcd:000A::/64
Step 04

Route Summarization

Summarization combines multiple smaller subnets into one larger advertisement, reducing the size of routing tables. Align the networks in binary and find the common bits.

Binary Summarization

Summarize 192.168.8.0/24 to 192.168.11.0/24.

summarization.txt
/* 8 = 00001000 */ /* 9 = 00001001 */ /* 10 = 00001010 */ /* 11 = 00001011 */ /* Common bits stop after the 6th bit from the left. */ /* 8 + 2 bits = 24 + 2 = /22 */ Summary Route: 192.168.8.0/22
