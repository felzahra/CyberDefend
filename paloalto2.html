1. Application & URL FilteringBlocking specific apps and websites

1
Block Social Media & File Sharing
Use App-ID to block applications like Facebook, Torrents, and Netflix regardless of port or protocol.
CLI CONFIGURATION
set rulebase security rules Block-Social-Media
    from Trust
    to Untrust
    source any
    destination any
    application [ facebook-base bittorrent netflix-streaming ]
    service application-default
    action deny
2
URL Filtering (Block Categories)
Block entire URL categories like gambling or adult content.
CLI CONFIGURATION
set rulebase security rules Block-Gambling-URLs
    from Trust
    to Untrust
    source any
    destination any
    application web-browsing
    category gambling
    service application-default
    action deny

2. Threat PreventionAntivirus, Anti-Spyware, & Vulnerability Protection

1
Create Security Profiles
Define Antivirus and Anti-Spyware profiles to inspect traffic.
CLI CONFIGURATION
# Create Antivirus Profile
set shared profiles virus Strict-AV
    decoder http action drop
    decoder smtp action drop
    decoder ftp action drop

# Create Anti-Spyware Profile
set shared profiles spyware Strict-AS
    rules threat severities [ critical high medium ]
    rules threat action drop
2
Attach Profiles to Security Rule
Apply the Threat Prevention profiles to your Allow-Outbound-Web rule.
CLI CONFIGURATION
set rulebase security rules Allow-Outbound-Web
    profile-setting profiles
        virus Strict-AV
        spyware Strict-AS

3. SSL Decryption (Forward Proxy)Inspecting HTTPS Traffic

1
Generate SSL Certificate
Create a self-signed CA certificate for SSL Forward Proxy.
CLI CONFIGURATION
set shared certificate Forward-Trust-Cert
    key-type RSA
    rsa-key-size 2048
    certificate-signed-by Forward-Trust-Cert
    name Forward-Trust-Cert
    algorithm RSA
    common Forward-Trust-Cert
    ca yes
2
Create Decryption Profile & Rule
Decrypt SSL traffic going from Trust to Untrust.
CLI CONFIGURATION
# Create Decryption Profile
set shared profiles decryption SSL-Forward-Profile
    ssl-forward-proxy yes

# Create Decryption Rule
set rulebase decryption rules Decrypt-Outbound
    from Trust
    to Untrust
    source any
    destination any
    application [ ssl web-browsing ]
    service any
    action decrypt
    profile SSL-Forward-Profile
    certificate Forward-Trust-Cert
⚠️
Warning: SSL Decryption requires a lot of CPU. Do not decrypt everything (like banking or financial sites) to avoid performance degradation and privacy issues.

4. Site-to-Site IPsec VPNConnecting two sites securely

1
Configure IKE Gateway
Define the Phase 1 parameters and peer IP.
CLI CONFIGURATION
set network ike gateway IKE-GW-SiteB
    authentication pre-shared-key key MySecretKey123!
    protocol ikev2
    ikev2
    peer-id-type ipaddr
    peer-address 203.0.113.10 # Remote Site B WAN IP
    local-address 203.0.113.2 # Local Site A WAN IP
    protocol-version ikev2
2
Configure IPsec Crypto Profile
Define the Phase 2 parameters (ESP, DH Group, Auth).
CLI CONFIGURATION
set network ipsec-crypto-profiles ipsec-crypto-profiles IPsec-Prof-SiteB
    esp encryption aes-256-gcm
    esp authentication sha1
    dh-group group14
    lifetime hours 8
3
Create Tunnel Interface & Bind to VR
Create a tunnel interface and assign it to the default virtual router.
CLI CONFIGURATION
set network interface tunnel tunnel.1 ip 172.16.100.1/30
set zone VPN network tunnel tunnel.1
set network virtual-router default interface tunnel.1
4
Create IPsec Tunnel
Tie together IKE Gateway, IPsec Profile, and Tunnel Interface.
CLI CONFIGURATION
set network ipsec-tunnels IPsec-Tunnel-SiteB
    auto-key ike-gateway IKE-GW-SiteB
    auto-key ipsec-crypto-profile IPsec-Prof-SiteB
    tunnel-interface tunnel.1
✅

PALO ALTO CLI
# Save and apply all configurations
commit
# Verify IPsec VPN Tunnel Status

For the VPN to work, you must also add a Security Policy allowing traffic from Trust to VPN zone, and a static route pointing traffic for the remote subnet (192.168.1.0/24) to tunnel.1.
