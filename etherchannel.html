EtherChannel

Bundle multiple physical links into a single logical link using LACP or PAgP for redundancy and increased bandwidth.

Step 01

Interface Prerequisites

All interfaces in an EtherChannel must have identical configurations (speed, duplex, VLAN, trunk mode) before they can be bundled.

SW1 & SW2 Configuration

Configure the physical interfaces (e.g., Gi0/1 and Gi0/2) as trunks, but do not enable them yet.

prerequisites.conf
SW1(config)# interface range gigabitEthernet 0/1 - 2 SW1(config-if-range)# switchport mode trunk SW1(config-if-range)# switchport trunk allowed vlan 10,20,30 SW1(config-if-range)# shutdown SW1(config-if-range)# exit ! Note: SW2 must be configured identically on its connecting ports.
Multiple Physical Links Bundled Together
Step 02

LACP Configuration (802.3ad)

LACP is the IEEE open standard protocol for negotiating EtherChannels. Configure the channel-group and assign it to the logical Port-Channel interface.

LACP Active Mode

Use "active" mode to actively initiate LACP negotiation. Run this on both SW1 and SW2.

lacp-config.conf
! Assign interfaces to Channel Group 1 using LACP active mode SW1(config)# interface range gigabitEthernet 0/1 - 2 SW1(config-if-range)# channel-group 1 mode active SW1(config-if-range)# no shutdown SW1(config-if-range)# exit ! Configure the logical Port-Channel interface SW1(config)# interface port-channel 1 SW1(config-if)# switchport mode trunk SW1(config-if)# switchport trunk allowed vlan 10,20,30 SW1(config-if)# exit
Step 03

PAgP Configuration (Cisco Proprietary)

Port Aggregation Protocol (PAgP) is Cisco's proprietary alternative to LACP. Use "desirable" mode to actively initiate negotiation.

pagp-config.conf
! Assign interfaces to Channel Group 2 using PAgP desirable mode SW1(config)# interface range gigabitEthernet 0/3 - 4 SW1(config-if-range)# channel-group 2 mode desirable SW1(config-if-range)# no shutdown SW1(config-if-range)# exit ! Configure the logical Port-Channel interface SW1(config)# interface port-channel 2 SW1(config-if)# switchport mode trunk SW1(config-if)# exit
Step 04

Layer 3 EtherChannel

For switch-to-router connections, you can configure a routed EtherChannel. Remove Layer 2 switching functionality before bundling.

Routed Port-Channel

Use "no switchport" on the physical interfaces and the Port-Channel to assign IP addresses directly.

l3-etherchannel.conf
! Remove Layer 2 settings on physical interfaces SW1(config)# interface range gigabitEthernet 0/5 - 6 SW1(config-if-range)# no switchport SW1(config-if-range)# channel-group 3 mode active SW1(config-if-range)# no shutdown SW1(config-if-range)# exit ! Configure the logical Port-Channel as a routed interface SW1(config)# interface port-channel 3 SW1(config-if)# no switchport SW1(config-if)# ip address 10.0.0.1 255.255.255.252 SW1(config-if)# no shutdown SW1(config-if)# exit
High-Bandwidth Core Switch Links
Step 05

Verification

Verify the EtherChannel status. Look for an "SU" (Layer 2, In Use) or "RU" (Layer 3, In Use) status, and ensure individual ports are bundled with a "(P)" flag.

verify-etherchannel.conf
SW1# show etherchannel summary Flags: D - down P - bundled in port-channel I - stand-alone s - suspended U - in use S - Layer 2 R - Layer 3 Group Port-channel Protocol Ports ------+-------------+-----------+----------------------------------------------- 1 Po1(SU) LACP Gi0/1(P) Gi0/2(P) 2 Po2(SU) PAgP Gi0/3(P) Gi0/4(P) 3 Po3(RU) LACP Gi0/5(P) Gi0/6(P) SW1# show etherchannel 1 port-channel Port-channels in the group: Port-channel: Po1 ------------ Age of the Port-channel = 0d:00h:05m:12s Logical slot/port = 2/1 Number of ports = 2 GC = 0x00010001 HotStandBy port = null Port state = Port-channel Ag-Inuse Protocol = LACP SW1# show spanning-tree summary ! Verifies STP sees the bundle as one logical link, avoiding blocking.
