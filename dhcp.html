DHCPv4 Configuration

Configure a router as a DHCP Server and use IP Helper to relay requests across different subnets.

Step 01

Exclude IP Addresses

Before creating a DHCP pool, exclude the IP addresses that are statically assigned (like routers, switches, and servers) so DHCP doesn't hand them out to clients.

R1 Configuration

We will exclude the default gateway and a few servers from the 192.168.10.0/24 network.

dhcp-excluded.conf
R1(config)# ip dhcp excluded-address 192.168.10.1 192.168.10.10 R1(config)# ip dhcp excluded-address 192.168.10.254
Core Router Acting as DHCP Server
Step 02

Configure DHCP Pool & Gateway

Create a named pool for the subnet, define the network range, and specify the default-router (gateway) IP address.

dhcp-pool.conf
R1(config)# ip dhcp pool SALES_LAN R1(dhcp-config)# network 192.168.10.0 255.255.255.0 R1(dhcp-config)# default-router 192.168.10.1 R1(dhcp-config)# exit
Step 03

Configure DNS & Domain Name

Clients need a DNS server to resolve domain names (like google.com) and optionally a domain name to register themselves.

dhcp-dns.conf
R1(config)# ip dhcp pool SALES_LAN R1(dhcp-config)# dns-server 8.8.8.8 8.8.4.4 R1(dhcp-config)# domain-name cyberdefend.local R1(dhcp-config)# exit
Layer 3 Relay

Configure DHCP Relay (IP Helper)

DHCP Discover messages are broadcasts. Routers do not forward broadcasts by default. If your DHCP server is on a different subnet, you must configure an IP Helper on the router interface facing the clients.

R2 Configuration (Relay Agent)

Assume R2 is the gateway for the IT_LAN (10.0.0.0/24), but the DHCP server (R1) is across the WAN at 172.16.0.1.

ip-helper.conf
R2(config)# interface gigabitEthernet 0/0 R2(config-if)# ip address 10.0.0.1 255.255.255.0 R2(config-if)# ip helper-address 172.16.0.1 R2(config-if)# no shutdown R2(config-if)# exit ! Note: R1 (The DHCP Server) must also have a DHCP pool configured for the 10.0.0.0/24 network!
Router Forwarding DHCP Broadcasts Unicast
Step 05

Verify DHCP Bindings

Verify which IP addresses have been leased to clients and check the pool statistics.

verify-dhcp.conf
R1# show ip dhcp binding Bindings from all pools not associated with VRF: IP address Client-ID/ Lease expiration Type Hardware address 192.168.10.11 0050.0FED.B8A1 -- Automatic 192.168.10.12 0050.0FED.B9C2 -- Automatic R1# show ip dhcp pool SALES_LAN Pool SALES_LAN : Utilization mark (high/low) : 100 / 0 Subnet size (first/next) : 0 / 0 Total addresses : 254 Leased addresses : 2 Excluded addresses : 11 Pending event : none ! On a Windows PC, verify IP assignment via CMD C:\> ipconfig /all IPv4 Address. . . . . . . . . . . : 192.168.10.11 (Preferred) Subnet Mask . . . . . . . . . . . : 255.255.255.0 Default Gateway. . . . . . . . . : 192.168.10.1 DHCP Server. . . . . . . . . . . : 192.168.10.1

All DHCPv4 Commands

Complete cheat sheet for DHCP Server, Relay Agent, and Verification commands.

CommandDescriptionMode
ip dhcp excluded-address [ip]Reserve IPs so they are not handed out by DHCPGlobal Config
ip dhcp excluded-address [start_ip] [end_ip]Reserve a range of IPsGlobal Config
ip dhcp pool [name]Create a DHCP pool and enter DHCP config modeGlobal Config
network [ip] [mask]Define the subnet of IP addresses to leaseDHCP Config
default-router [ip]Define the default gateway for clientsDHCP Config
dns-server [ip]Define DNS servers for clientsDHCP Config
domain-name [name]Define domain name for clientsDHCP Config
lease [days] [hours] [mins]Change IP lease duration (Default is 1 day)DHCP Config
ip helper-address [ip]Forward DHCP broadcasts to a server on another subnetInterface Config
show ip dhcp bindingView list of assigned IP addresses and client MACsPrivileged EXEC
show ip dhcp pool [name]View pool statistics (leased, excluded, total)Privileged EXEC
show ip dhcp server statisticsView DHCP message counters (Discovers, Offers, etc.)Privileged EXEC
clear ip dhcp binding [ip | *]Clear current DHCP lease bindingsPrivileged EXEC
no service dhcpDisable DHCP service globally on routerGlobal Config
