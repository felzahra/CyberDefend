Ransomware Simulation

Simulate a ransomware payload encrypting files on a Windows target, and learn how to block it.

1
Create a Test Directory

On the Windows target machine, create a folder with dummy text files.

mkdir C:\TestFiles
echo "Important Data" > C:\TestFiles\file1.txt
echo "More Data" > C:\TestFiles\file2.txt

2
Execute Simulated Encryptor

Run a simulated ransomware script (or use a tool like CryptoLocker Simulator). This script will append .locked to the files.

powershell -Command "Get-ChildItem C:\TestFiles\* -Include *.txt | Rename-Item -NewName { $_.name + '.locked' }"

3
Observe Impact

List the directory contents. You will see the original files are no longer accessible because they have been "encrypted" (renamed).

dir C:\TestFiles
🛡️ Mitigation (Fortinet Firewall): Enable Anti-Malware and CDR (Content Disarm & Reconstruction) to strip malicious macros and payloads from files before they reach the endpoint. 
config antivirus profile
    edit Block-Ransomware
        set ftgd-wf block
        set scan-mode full
        config ftgd-wf-options
            set error-action block
        end
