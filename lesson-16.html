By Dan Nanni · study-notes.org
OSI Layer
⚙️Functions
🥷Attack Vectors
Application
Layer
  • User interface & app-level service
  • Web browsing, email, file transfer
  • HTTP, SMTP, DNS protocols
  • 1 Malware injection
  • 2 Phishing attacks
  • 3 App-level DDoS attacks
Presentation
Layer
  • Data encryption and decryption
  • Data compression and expansion
  • Data format conversion
  • 1 Exploiting weak encryption
  • 2 File format exploits
  • 3 Malicious code injection
Session
Layer
  • Create & terminate app sessions
  • Manage session state
  • Video conferencing session
  • 1 Session hijacking & replay
  • 2 Session fixation attack
  • 3 TLS/SSL renegotiation
Transport
Layer
  • End-to-end data delivery
  • TCP and UDP protocols
  • Error correction & congestion ctrl
  • 1 TCP/SYN & UDP flood attack
  • 2 TCP hijacking & MITM
  • 3 Port scan for vulnerability
Network
Layer
  • Routing and IP addressing
  • IPv4, IPv6 and routing protocols
  • Packet filtering configuration
  • 1 IP spoofing & fragmentation
  • 2 Ping of death & ICMP flood
  • 3 Route poisoning attacks
Data Link
Layer
  • Frames and physical addressing
  • Error detection and correction
  • Switching & VLAN configuration
  • 1 ARP spoofing & poisoning
  • 2 STP attack & MAC spoofing
  • 3 Wireless vulnerability attacks
Physical
Layer
  • Ethernet cables signaling
  • Ethernet cables and fiber optics
  • Physical layer configuration
  • 1 Data interception & tampering
  • 2 Signal jamming
  • 3 Unauthorized device install

Types of Internet Threats

12 major categories of cyber threats. Think before you click.

Virus

Attaches to clean files and replicates when executed.

Malware

Umbrella term for all harmful software.

Spyware

Secretly monitors user activity and collects data.

Adware

Delivers unwanted advertisements and collects data.

Ransomware

Encrypts files and demands payment for decryption.

Trojan Horse

Disguised as legitimate software to trick users.

Worms

Self-replicating malware spreading without user interaction.

Phishing

Deceptive emails/websites to steal sensitive information.

Botnet

Network of compromised devices for malicious tasks.

Rootkit

Hides malware and maintains stealthy system access.

Keylogger

Records every keystroke to steal sensitive input.

DDoS Attack

Overwhelms targets with massive traffic.

Penetration Testing Concepts

Simulating cyberattacks to identify weaknesses before malicious actors exploit them.

Penetration Testing Types

Black Box

Zero knowledge of IT infrastructure

White Box

Full knowledge of IT infrastructure

Grey Box

Some knowledge of IT infrastructure

Areas of Penetration Testing

  • Network Services: Infrastructure, protocols, services
  • Web Application: OWASP Top 10, API security
  • Client Side: Workstation software vulnerabilities

1. BURP SUITE

Basic: $ burpsuite

$ burpsuite --help
 $ burpsuite --version
 $ burpsuite --project-file <file>
 $ burpsuite --config-file <file>
 $ burpsuite --install-cert

2. NUCLEI

Basic: $ nuclei -u <url>

$ nuclei -l list.txt
 $ nuclei -t <template-path>
 $ nuclei -tags <tag1,tag2>
 $ nuclei -severity low,medium,high,critical
 $ nuclei -o output.txt

3. SUBFINDER

Basic: $ subfinder -d example.com

$ subfinder -dL domains.txt
 $ subfinder -silent
 $ subfinder -all
 $ subfinder -sources crtsh,shodan
 $ subfinder -oJ

4. FFUF

Basic: $ ffuf -u https://target/FUZZ -w wordlist.txt

$ ffuf -X <method>
 $ ffuf -mc <code>
 $ ffuf -fs <size>
 $ ffuf -t <threads>
 $ ffuf -e .php,.bak

5. SQLMAP

Basic: $ sqlmap -u "https://target.tld/page.php?id=1" --batch

$ sqlmap --dbs
 $ sqlmap -D appdb --tables
 $ sqlmap -D appdb -T users --columns
 $ sqlmap --forms
 $ sqlmap --threads=5

6. OWASP AMASS

Basic: $ amass enum -d example.com

$ amass enum -passive -d example.com
 $ amass enum -brute -w wordlist.txt -d example.com
 $ amass enum -o results.txt -d example.com

7. HTTPX

Basic: $ cat hosts.txt | httpx

$ httpx -l hosts.txt -status-code -title -ip
 $ httpx -tech-detect
 $ httpx -follow-redirects
 $ httpx -threads <n>

8. KATANA

Basic: $ katana -u https://example.com

$ katana -list targets.txt
 $ katana -d 2
 $ katana -proxy http://127.0.0.1:8080
 $ katana -o results.txt

Pro Tip

Combine tools: discover with Amass/Subfinder, probe with httpx, find vulns with Nuclei, validate with Burp Suite & SQLmap.

Types of Malware

MALicious softWARE — threats that harm systems, steal data, or disrupt operations.

  1. Virus: Attaches to files and spreads when executed. (Melissa, CIH)
  2. Worm: Self-replicates across networks without user interaction. (Conficker, Stuxnet)
  3. Trojan: Disguised as legitimate software. (Zeus, Emotet)
  4. Ransomware: Encrypts files and demands payment. (WannaCry, Ryuk)
  5. Spyware: Secretly monitors user activity. (CoolWebSearch, FinFisher)
  6. Rootkit: Hides malware and provides stealthy access. (TDSS, ZeroAccess)
  7. Keylogger: Records keystrokes to steal sensitive data.
  8. Botnet: Remotely controlled infected devices. (Mirai)

Protection Tips

  • Keep software updated
  • Use trusted antivirus and firewall
  • Avoid suspicious emails
  • Download only from official sources
  • Use strong passwords and MFA
  • Take regular backups

SOC Logs: Eyes & Ears of Cybersecurity

Logs are the foundation of security monitoring and incident response.

System Logs

OS events, boot sequences, service status, kernel messages. Critical for detecting unauthorized changes.

Security Logs

Authentication attempts, access controls, policy changes, privilege escalations.

Network Logs

Firewall rules, NAT translations, VPN connections, routing changes, DNS queries.

Web Logs

HTTP requests, response codes, user agents, URLs accessed, error logs.

Database Logs

Query logs, login attempts, schema changes, backup events, performance metrics.

Email Logs

SMTP transactions, delivery status, spam filtering, attachment scanning.

Types, Testing Scopes, and Essential Tools

Zero knowledge of internal IT infrastructure prior to testing.
