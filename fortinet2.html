1 · Introduction & Prerequisites What is FortiGate and why GNS3?

💡
FortiGate is one of the world's largest cybersecurity companies. FortiOS is their proprietary operating system used on FortiGate firewalls — completely different architecture, CLI syntax, and policy model from Cisco IOS.
🎯
Why GNS3? It supports FortiGate KVM which runs actual FortiOS in a virtual environment — giving you a real firewall experience, not a simulation.
⚠️
Requirements: GNS3 2.2+ (2.2.41 recommended), 8GB+ RAM, 30GB+ free disk, Internet for image download.
Tip: FortiOS KVM is free for personal/evaluation use from the Fortinet Support portal. You need a free Fortinet account.
📥

6 · Configure Interfaces Internal + External + DMZ

💡
FortiGate uses port-based security zones: Internal, External, DMZ. Each zone has its own policies.
A
Configure Internal Port
Connect to internal LAN
FORTiOS — INTERNAL INTERFACE
FGT-LAB # config system interface
FGT-LAB (interface) # edit "internal"
FGT-LAB (internal) # set ip 10.0.1.1 255.255.255.0
FGT-LAB (internal) # set allowaccess ping https ssh
FGT-LAB (internal) # next
FGT-LAB (interface) # end
B
Configure External (WAN) Port
Connect to external network / internet
FORTiOS — EXTERNAL INTERFACE
FGT-LAB # config system interface
FGT-LAB (interface) # edit "wan1"
FGT-LAB (wan1) # set ip 192.168.1.254 255.255.255.0
FGT-LAB (wan1) # set allowaccess ping
FGT-LAB (wan1) # next
FGT-LAB (interface) # end
C
Configure DMZ Port
Demilitarized zone for public-facing servers
FORTiOS — DMZ INTERFACE
FGT-LAB # config system interface
FGT-LAB (interface) # edit "dmz"
FGT-LAB (dmz) # set ip 172.16.0.1 255.255.255.0
FGT-LAB (dmz) # set allowaccess ping
FGT-LAB (dmz) # next
FGT-LAB (interface) # end
VERIFY INTERFACES
FGT-LAB # get system interface physical
Note: If a port shows "down", make sure the GNS3 link is connected. FortiOS interfaces auto-negotiate speed.

7 · Default Route 0.0.0.0/0

💡
FortiOS can auto-generate a default route, but always configure explicit static routes on real firewalls.
FORTiOS — DEFAULT ROUTE
FGT-LAB # config router static
FGT-LAB (static) # edit 0
FGT-LAB (0) # set dst 0.0.0.0 0.0.0.0
FGT-LAB (0) # set gateway 192.168.1.1
FGT-LAB (0) # set device "wan1"
FGT-LAB (0) # next
FGT-LAB (static) # end
VERIFY
FGT-LAB # get router info routing-table all
🎯
Why explicit? Auto-generated default routes can cause asymmetric routing. Always define them manually.
🛡️

8 · Firewall Policies The core of FortiOS security

💡
FortiOS uses zone-based policies — unlike Cisco ACLs which are interface-based. Policies are applied to traffic between zones.
A
Allow Internal → External
Standard outbound internet access
POLICY: INTERNAL → EXTERNAL
FGT-LAB # config firewall policy
FGT-LAB (policy) # edit 1
FGT-LAB (1) # set name "Internal-to-External"
FGT-LAB (1) # set srcintf "internal"
FGT-LAB (1) # set dstintf "wan1"
FGT-LAB (1) # set srcaddr "all"
FGT-LAB (1) # set dstaddr "all"
FGT-LAB (1) # set action accept
FGT-LAB (1) # set schedule "always"
FGT-LAB (1) # set service "ALL"
FGT-LAB (1) # set logtraffic all
FGT-LAB (1) # next
FGT-LAB (policy) # end
B
Allow Internal → DMZ
Access to DMZ servers
POLICY: INTERNAL → DMZ
FGT-LAB # config firewall policy
FGT-LAB (policy) # edit 2
FGT-LAB (2) # set name "Internal-to-DMZ"
FGT-LAB (2) # set srcintf "internal"
FGT-LAB (2) # set dstintf "dmz"
FGT-LAB (2) # set srcaddr "all"
FGT-LAB (2) # set dstaddr "all"
FGT-LAB (2) # set action accept
FGT-LAB (2) # set schedule "always"
FGT-LAB (2) # set service "HTTP" "HTTPS" "DNS"
FGT-LAB (2) # set logtraffic all
FGT-LAB (2) # next
FGT-LAB (policy) # end
C
Deny External → Internal
Block all unsolicited inbound traffic
POLICY: DENY EXTERNAL → INTERNAL
FGT-LAB # config firewall policy
FGT-LAB (policy) # edit 3
FGT-LAB (3) # set name "Deny-External-to-Internal"
FGT-LAB (3) # set srcintf "wan1"
FGT-LAB (3) # set dstintf "internal"
FGT-LAB (3) # set srcaddr "all"
FGT-LAB (3) # set dstaddr "all"
FGT-LAB (3) # set action deny
FGT-LAB (3) # set schedule "always"
FGT-LAB (3) # set service "ALL"
FGT-LAB (3) # set logtraffic all
FGT-LAB (3) # next
FGT-LAB (policy) # end
VERIFY POLICIES
FGT-LAB # show firewall policy

9 · NAT (Source NAT) Hide internal IPs behind external

💡
FortiOS applies NAT inside firewall policies using the set nat enable option — no separate NAT command needed.
NAT INSIDE POLICY (edit existing policy 1)
FGT-LAB # config firewall policy
FGT-LAB (policy) # edit 1
FGT-LAB (1) # set nat enable
FGT-LAB (1) # next
FGT-LAB (policy) # end
🎯
That's it! Unlike Cisco where you configure ip nat inside/outside separately, FortiOS NAT is a single line inside the policy.
Note: set nat enable does IP masquerade (overwrite source IP with outgoing interface IP). For port forwarding (DNAT), use config firewall vip.
📡

10 · DHCP Server Auto-assign IPs to internal hosts

FORTiOS — DHCP SERVER ON INTERNAL
FGT-LAB # config system dhcp server
FGT-LAB (dhcp-server) # edit 1
FGT-LAB (1) # set status enable
FGT-LAB (1) # set interface "internal"
FGT-LAB (1) # set ip-range 10.0.1.10 10.0.1.100
FGT-LAB (1) # set default-gateway 10.0.1.1
FGT-LAB (1) # set dns-server 8.8.8.8 8.8.4.4
FGT-LAB (1) # set netmask 255.255.255.0
FGT-LAB (1) # next
FGT-LAB (dhcp-server) # end
VERIFY DHCP
FGT-LAB # execute dhcp lease-list
⚠️
Important: Make sure the DHCP range doesn't overlap with the interface IP. Interface is 10.0.1.1, so range starts at 10.0.1.10.

✅ Summary & Key Takeaways

  • FortiOS KVM runs real firewall OS in GNS3 — not a simulation
  • Interfaces are configured under config system interface with zone assignment
  • Firewall policies are zone-based, not interface-based like Cisco ACLs
  • NAT is a single line (set nat enable) inside the policy — no separate config
  • DHCP server is built-in — configure under config system dhcp server
  • Always configure explicit default routes — don't rely on auto-generated ones
  • Use execute save to persist config (like copy run start)
  • Default login: admin/admin — change immediately in production
  • GUI available at https://<interface-ip> — powerful web dashboard
  • Backup configs regularly with show full-configuration or TFTP export
